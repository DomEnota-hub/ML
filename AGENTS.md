# MediaLoader: обязательный регламент CI

Актуальный источник: docs/ci/README.md. Старый порядок сборки отменён. Рабочая база разработки — feature/ml-17211-simple-archive-replacement (PR #172); инфраструктура уже интегрирована. Не переносить изменения на main и не публиковать релиз без отдельной приёмки. Версия 1.7.211/271 забракована на устройстве (VerifyError); не распространять её.

Единственный штатный маршрут CI приложения — .github/workflows/ml-ci.yml.
**Промежуточные коммиты, открытие и обновление PR не запускают CI/Gradle.** Только явный workflow_dispatch или добавление метки ci:verify/ci:qualify; Quick исключительно вручную. По решению владельца от 24.11.2026 постоянно разрешены промежуточные quick, а при недостаточном покрытии quick или отсутствии доступного ручного dispatch — verify через единственный ml-ci.yml, если локального окружения недостаточно для обязательной адресной проверки этапа. Отдельное разрешение на каждый такой запуск не требуется. Проверять точный HEAD, не дублировать активные запуски; APK и подпись только после итогового qualify. При достаточном локальном покрытии промежуточный CI не нужен. Один итоговый qualify на финальном HEAD. Не запускать отдельный Gradle ради этой правки CI.
Режимы quick (быстрая обратная связь), verify (полная JVM + lint, без APK), qualify (JVM + lint + ARM64 + DEX + exact-source receipt), perf (отдельный бенчмарк). ci:verify и ci:qualify взаимоисключающие. Не запускать повторно активный CI; опрос примерно каждые 60 секунд до терминального статуса в пределах активного сеанса. Не использовать эмулятор. Не считать статический CI заменой проверки на реальном устройстве.

scripts/run-jvm-ci.py — единственный штатный полный runner: один bulk + один граф Gradle с отдельной Test-задачей и JVM на каждый изолированный метод. Не восстанавливать старый runner, режим audit, удалённые YAML и архив из Git-истории. docs/ci/allowed-workflows.json — разрешённые семь workflow; изменения только после явной сверки назначения. Пять исследовательских workflow не являются альтернативой сборке; инструмент подписи выдаёт только инструменты без секретов.

Сохранить состав 2359 проверенных JVM-идентификаторов (2358 PASS, 1 явно разрешённый Shazam skip на 1.7.211); новые/удалённые идентификаторы требуют осмысленной сверки. Не ослаблять тесты, не скрывать ошибки и не повторять функциональные сбои ради зелёного статуса. Семантический аудит необходимости каждого теста отложен отдельно по решению пользователя.

Перед подписанием проверять успешное завершение exact-SHA qualification, live HEAD, все хеши и DEX; повторить DEX на окончательном подписанном APK. GAPI и ключи подписи вне GitHub. Выдача только Google Drive, ARM64, точные исходники отдельным архивом, без Releases/prereleases. Реальная проверка Xiaomi обязательна прежде стабильного выпуска. Не восстанавливать старые сборочные маршруты из других веток. Сводка.md и Правила.md должны ссылаться на этот регламент.
