# MediaLoader / Загрузчик

Android-приложение для сохранения медиа из поддерживаемых источников.

## Текущее состояние

- Instagram: фото, видео, аудио, авторизация через WebView/sessionid.
- YouTube: анализ и загрузка видео/аудио через yt-dlp, обновление yt-dlp из приложения, экспериментальная web-сессия YouTube.
- Локальная история загрузок, корзина, переименование, системная папка загрузок.
- Диагностические логи открываются пятью нажатиями на «О приложении» и экспортируются в Markdown.

## 1.5.7

- Встроенный просмотр видео, аудио и фото с внешним fallback.
- Видеоредактор: временная обрезка, пространственное кадрирование, поворот, удаление звука и извлечение аудио.
- Аудиоплеер: фон, очередь, повтор, предыдущий/следующий и мини-плеер.
- Аудиоредактор: обрезка, название, исполнитель, альбом и обложка.
- Просмотр фото: зум, двойной тап, карусель и сведения о файле.
- Фоторедактор: кадрирование, пропорции, поворот и отражение.
- Тяжёлая обработка медиа продолжает работать через foreground service.
