## Звук

Подтверждено по коду: цикл синхронизации зависел от всего проекта и перезапускался на каждой записи границы аудио. Теперь цикл стабилен, актуальный проект читается через rememberUpdatedState. Во время живого жеста аудиоплееры приостановлены, маршрутизация применяется после отпускания. Никакой обработки исходного файла во время редактирования не добавлялось.

Коррекция отдельного аудиоплеера имеет интервал не менее 750ms при воспроизведении; явная перемотка и вход в слышимый диапазон выполняются сразу. Естественное продвижение позиции сравнивается с прошедшим реальным временем, чтобы задержка UI более 250ms не считалась автоматически пользовательским seek. При коррекции не выполняется лишняя пара pause/play. Существующий видеоплеер продолжает воспроизводить совпадающий по времени оригинальный звук; диапазон управляет его громкостью. Экспорт остаётся по существующей модели дорожек.

Добавлены журнал AudioRoute при переключении маршрута и ограниченные расширенные записи AudioSync для перемоток. Они позволяют проверить реальную ветку выполнения на телефоне. Причина всех пользовательских рывков без нового журнала и устройства не считается окончательно установленной.

Статус PARTIAL / NOT_DEVICE_TESTED: нужны серии START/END, отпускание, перемотка, пауза/запуск, перенос, скорость, Undo/Redo и MP4 с AAC. Плавность, мгновенный запуск и экспорт не объявляются проверенными по JVM-тестам.
