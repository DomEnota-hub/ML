# MediaLoader 1.7.100 (162)

## Галерея и музыка

- Первый проход по телефонной библиотеке публикует найденные файлы порциями;
  не нужно ждать последнего файла, чтобы увидеть первую страницу.
- Промежуточные результаты тоже сохраняются на диске. После перезапуска они
  восстанавливаются с прежними проверками разрешений/приватности и сверяются в фоне.
- При отсутствии защищаемых физических копий убраны массовые индивидуальные
  открытия файлов, если путь недоступен. Для защиты «Личного» необходимые
  проверки физической идентичности сохранены.
- Индексация истории приложения отделена от обновлений телефонного списка:
  обновление больше не перезапускает её. История обрабатывается порциями,
  с ограничением в восемь параллельных запросов. Корзина и приватные файлы не
  обходятся как часть публичного каталога.
- Добавлены безопасные диагностические счётчики этапов и длительности, без путей.

## Просмотр из сетки «Загрузчика»

Публичные фото/видео открываются в общем просмотрщике галереи. Перелистывание
свайпами следует текущей сетке и её фильтрам, пересекает группы, включает видео.
Боковых стрелок нет. Псевдонимы разрешаются только через проверенный публичный
индекс; сырые записи истории не обходят защиту «Личного».

## Удаление

- Убраны дублирующие окна и имена файлов в подтверждениях приложения.
- Одно общее подтверждение с количеством для объекта/группы; «Удалить» красным.
- Для телефонных файлов без специального доступа используется системное окно
  Android, без предварительных окон приложения.
- В настройках добавлен добровольный доступ «Управление медиафайлами» на
  Android 12+. При его выдаче остаётся подтверждение приложения, а дополнительный
  запрос MediaStore не показывается. Этот доступ включает MediaStore-аудио;
  сторонние SAF-провайдеры сохраняют собственные ограничения.
- Существующее назначение операции сохранено: загрузки приложения → корзина,
  файлы телефона → удаление через MediaStore.

## Проверка и выпуск

Только целевые проверки сканера, публикации индекса, очереди сетки,
разрешения псевдонимов просмотрщика и текста подтверждения. Без полного
набора тестов и эмулятора по просьбе пользователя. Итоговые результаты,
подпись и ссылка на Drive записываются после завершения сборки.
Поведение на реальном телефоне и конкретном OEM-провайдере проверяет пользователь.
