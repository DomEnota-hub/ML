Исследовать параллельные независимые группы/runner lanes с ограничением памяти и сохранением отдельных свежих JVM, exact IDs и markers; не объединять методы в один процесс без отдельного доказательства. Эксперимент только после проверки архитектуры Gradle: --parallel сам по себе не гарантирует параллельность задач одного проекта.
3. Quick navigation выполняет 35/37 изолированных методов. Сузить тематические профили после dependency/semantic audit, не только по названиям. Перенести исторические baseline tests в соответствующие профили только с доказанным покрытием и сохранением обязательных guards. Не удалять тесты из full.
