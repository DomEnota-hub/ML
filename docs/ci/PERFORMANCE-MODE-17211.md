HistoricalReferenceQueryBenchmarkTest (two existing mandatory IDs; 34.862 s combined in baseline XML) remains in full JVM. It still creates all 512 synthetic rows, checks both paths and all 1/4/20-source cases, fresh/reused connections, schema/count assertions, and both diagnostic logging modes. This is a test-only change, not a speed threshold change or omitted required ID. Full original measurement loops are opt-in via workflow_dispatch mode=perf or Gradle -PmlPerfBenchmarks=true. Perf emits diagnostics only, never a qualification receipt or APK. No emulator. Savings and parity of actual Kotlin execution remain to be measured on a JVM CI run. All 40 isolated Compose methods are preserved until fresh-worker alternative is proven equivalent. No app code changes or new APK in this stage.
