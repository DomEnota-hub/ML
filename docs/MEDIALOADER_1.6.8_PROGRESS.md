База: проверенный CI коммит 1.6.7 (47), `dd415f364f92c5ad69e6ca6b97544466f1565494`.

- [x] Этап 0. Аудит: ветки public page/embed и порядок извлечения подписи, подтверждённая ошибка истории для Apple/Shazam artwork, повторные сетевые тайм-ауты CDN; проверен базовый код локальных миниатюр и повторного Shazam.
- [x] Этап 1. Instagram: исправлен путь embed с незаполненным названием, generic CDN-имена допускают восстановление из проверенного описания; очистка Unicode-хэштегов сохраняется. Тесты добавлены.
- [x] Этап 2. Превью: история принимает HTTPS Apple/Shazam арт без sourceHint, сохраняются любые проверенные обложки, видео выбирает кадр ближе к 1.5с, есть лимит дискового кэша. Пропавший оригинал и 403 не обещают восстановления.
- [x] Этап 3. HitMoz: временная диагностика проблемного CDN и отказ от бесконечного повторного обращения к одному недоступному адресу; сохранился из 1.6.7 резервный platform HTTP transport, безопасный список перенаправлений.
- [x] Этап 4. Поиск: наследуем исправления 1.6.7 (отмена старой выдачи и pending selection при правке, точный guard URL/ревизии, ограниченный HTTP fallback); отдельно проверить полные сценарии на телефоне.
- [x] Этап 5. Shazam: повторение короткого аудио больше не подаётся как распознавание нового участка. Защита от замены метаданных без подтверждения сохраняется.
- [x] Этап 6. Журнал: локальные объяснения и советы к известным событиям, переключатель в просмотре, отдельный opt-in экспорта. Обычный технический лог неизменен по умолчанию.
- [x] Этап редактора: контракты подключения offline inpainting, отдельный план 1.7.0; тяжёлые модели и UI не добавлялись.
- [ ] Этап 7. Общие unit tests, Android lint, ARM64 APK, сверка подписи, доставка в Google Диск.
- [ ] Проверка на физическом Android: разные Instagram Reels одного автора, проблемные CDN, VPN, Shazam и обложки после перезапуска.

## Известные ограничения и правила
- Никаких автоматических подстановок номера CDN вместо адреса, возвращённого источником.
- Не считать все HTTP 403 восстановимыми.
- Не считать невыполненные живые испытания пройденными.
- Старый APK 1.6.7 не заменять; выпустить один подписанный ARM64 APK с новой версией.
- Подпись только локальным ключом DomEnota, никогда не включать секреты в GitHub.
