# Основной режим — интерактивный HTML, первый эскиз

Файл: `index.html`. Полностью самостоятельный: стили, сценарии и четыре
демонстрационных обложки встроены; Интернет и сервер не нужны.
Откройте файл в браузере. Изображения переиспользованы из согласованного
HTML библиотеки, реальные файлы/аккаунты пользователя не читаются.

## Точка продолжения

Пользователь возобновил работу над UI основного режима после исправлений1.7.101.
Ранее обсуждались нижние вкладки Главная / Загрузки / Инструменты и настройки
по шестерёнке. Отдельного сохранённого HTML этого режима не было.
Этот макет — конкретное предложение для просмотра, не согласованный новый
контракт всех экранов и не уже перенесённый Android-интерфейс.
Последняя версия APK остаётся1.7.101/code163. Продуктовый Kotlin не менялся.

## Предложенная структура

- Главная: поле ссылки и основная кнопка в начале; четыре компактных источника;
  состояние очереди; недавние файлы.
- Загрузки: поиск/папки/Личное сверху, фильтры источников и типов, активные задачи
  отдельно от истории. Выделение и групповые действия доступны из верхней панели.
- Инструменты: редакторы, массовая загрузка, VK, поиск песни, эквалайзер.
- Настройки: сгруппированные страницы вместо одной длинной ленты. Доступ по
  шестерёнке с главной/инструментов; прежние возможности не должны исчезать.
- Общий мини-плеер: обложка, предыдущий/пауза/следующий/закрыть, тонкий прогресс.
- Внешний вид: токены вариантаA Галереи/Музыки, тёмная и светлая темы.

## Проверено без Android-сборки

- `node --check` — синтаксис JS.
- Один сценарий в Chromium/Playwright: ввод ссылки → формат → миниатюра открывает
  предпросмотр → возврат → карточка выбирает720p → пример попадает в очередь.
- Выбор всех видимых файлов, подтверждение/отмена удаления, выход из выделения.
- Все26 маршрутов отрисовываются без ошибокJS и без переполнения `#app`.
- На ширине360px нет горизонтального переполнения страницы.
- Снимки главной, загрузок, инструментов, форматов, настроек и светлой темы.
- После уплотнения отступов главной повторно проверен синтаксис и сняты её две темы.

Среда Chromium запрещает file:// своим административным правилом, поэтому
проверка загружала локальный HTML через `page.set_content`; сетевого сервера нет.
Промежуточная ошибка глобального имени `top` исправлена именем `screenTop`.
Первоначальное переполнение360px исправлено minmax(0,1fr)/min-width:0.
Автотесты Android, сборкаAPK и публикация новой версии здесь не требовались.

## Предложенный порядок переноса после просмотра макета

1. Каркас основного режима: Tools route, три нижние вкладки, шестерёнка настроек.
   Сохранить Settings route и сохранённые состояния; не ломать навигацию других режимов.
2. Главная: компактные источники, URL-поле/анализ, очередь и недавние. Подключать
   существующие callbacks, без изменения поведения анализа/загрузки.
3. Загрузки и выбор формата: внешний вид, компактность, фильтры/выделение и
   панель действий. Сохранить реальные группы, статусы, папки и privacy gates.
4. Инструменты и группировка настроек: переиспользовать реальные назначения
   браузера/массовой загрузки/VK/редакторов, не дублировать хранилища и настройки.
5. Подробности редакторов — отдельно согласовать; не считать заглушки макета
   готовым заданием на перестройку редакторов.

Для каждой законченной части — небольшой checkpoint и только относящиеся к
изменению проверки. Не запускать заново полные690проверок библиотеки.
