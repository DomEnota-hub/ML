# v6 — новый макет по папкам разделов

Основа: v5 +14скриншотов «Образцы → Основное меню» и вложенные6папок;
точные DriveID в ../screenshots-drive-index.json. Дополнительная правка пользователя:
в конце главной ленты «Ещё», наши функции внутри и в визуальном стиле образца.

## Изменения

- Стартовый экран — главное меню редактора, шесть исходных разделов в ленте.
  «Ещё» идёт последним, доступен горизонтальной прокруткой. Внутри Сохранить кадр /
  Извлечь аудио и возврат, в том же чёрном интерфейсе с векторными значками.
  В верхнем ⋮ эти наши пункты больше не дублируются; его исходный состав пока
  не показан, поэтому он честно открывает сообщение об отсутствующем образце.
- Постер — кроп только содержимого превью из предоставленного JPEG, без системных
  элементов/личных уведомлений. Стартовый макет7,2с, без имитации проигрывания
  реального исходного ролика. Своё видео открывается отдельно.
- Соотношение сторон: Исходное,1:1,3:4,4:3,16:9,9:16,2.39:1,2.55:1.
  Плитки/выделение/подвал по снимкам; пропорции меняют рамку предпросмотра.
  Применение/отмена/undo восстанавливают состояние. Это модель проекта/превью;
  кодирования MP4 и обещания экспорта всех геометрических изменений нет.
- Выбор музыки: заголовок/назад, Онлайн / На устройстве, Импорт, цветные миниатюры,
  прослушивание, длительность, корзина и жёлтый +. Реальный импорт своих аудиофайлов
  и проигрывание в браузере. Два синтезированных демозвука генерируются локально
  при открытии, без сети/чужих музыкальных файлов/добавленных пользовательских имён.
  Онлайн-каталог не подключён и не подменён вымышленными треками.
- Фиолетовая дорожка: отдельные фрагменты/выделение; Изменить, Громкость,
  Обрезка (разрезание в позиции курсора), Копировать, Удалить. Разделение требует
  минимум0,5с с каждой стороны; копия добавляется при наличии места после фрагмента.
  Один слой музыки, несколько последовательных фрагментов; добавление нового трека
  заменяет выбранный фрагмент. Произвольное перетаскивание/микширование нескольких
  музыкальных слоёв не реализовано. Амплитудная фигура импортированных файлов пока
  декоративная; у демозвуков построена по сгенерированным отсчётам.
- Исправлены пустые первые миниатюры временной шкалы, видимость длительности вне
  выбора клипа, перенос подписей, добавлены цветные векторные значки Насыщенность /
  Красочность и значки импорта/изменения музыки.
- Панели текста, коррекции, фильтров и Save продолжают v3–v5. Не заявляется
  полное совпадение каждого глифа, точных LUT или всех нераскрытых состояний.
  Редактор титров/полный каталог эффектов по-прежнему требуют дополнительного образца.
  Наш реальный Android-редактор/версии/сборки не менялись.
