Критерии для реализации

Фильтры: список и количество берутся из нашего макета фоторедактора. Это единый пополняемый каталог для фото и видео; при добавлении фильтров в фоторедактор они должны становиться доступны и в видеоредакторе. Текущая демонстрационная подборка не задаёт окончательный список.

Иконки и их пропорции сверяются со скриншотами образца. При движении границы обрезки предпросмотр показывает соответствующий кадр начала или конца в реальном времени. Указатель позиции ограничен областью дорожек, подписи разделов и коррекции видны полностью.
