# Xiaomi Gallery и редактор MediaLoader: сверка 02.11.2026

Проверен исходный код на checkpoint `4d21994`; Android не собирался и не менялся.
Это аудит реализации, а не подтверждение работы на конкретном телефоне.

## Источники и границы

1. [Официальное руководство HyperOS, печатные страницы 86–90](https://gl123.alsgp0.mi-fds.com/gl123/Generic%20User%20Guide%20for%20HyperOS/Generic%20User%20Guide%20for%20HyperOS%20%28final%E4%BA%A4%E4%BB%98%29_1.11%E6%9B%B4%E6%96%B0.pdf).
   Различает простой экран редактирования и расширенный Video editor / Pro.
   Описывает скорость, разделение, импорт нескольких видео, переходы, шаблоны,
   фильтры, коррекцию изображения, текст/титры, громкость/музыку, пропорции.
2. [Официальная справка POCO X7 Pro](https://www.mi.com/global/support/faq/details/KA-529563/)
   отдельно перечисляет Video editor, Clip и функции обработки фотографий.
   Нельзя считать AI Eraser/AI Expansion функциями временной шкалы видеоредактора.
3. Пользовательские записи «Образцы / Видео» и дополнительная запись 7,38 с.
   Они остаются визуальным эталоном именно пользовательской версии интерфейса.

Функции и расположение элементов различаются между версиями Gallery/HyperOS,
моделями и регионами. Общая инструкция не доказывает наличие каждого пункта в
конкретной записи. Точные LUT фильтров, полный каталог ресурсов и окно Save
интернет-источниками не установлены. Состояния после Save ещё нужны от пользователя.

## Сравнение

| Возможность | Xiaomi: подтверждение | MediaLoader Android | Текущий HTML |
|---|---|---|---|
| Начало/конец фрагмента | Руководство, запись | Есть, реальный MP4 | Есть модель и предпросмотр |
| Несколько клипов, разрезание, копирование/замена/удаление | Импорт/разрезание — руководство; дополнительные действия — запись | Нет: один источник, один интервал | Есть модель клипов; общего MP4-экспорта нет |
| Переходы и шаблоны | Руководство расширенного редактора | Нет | Нет; в записи соответствующие состояния не показаны |
| Скорость | Руководство, запись 0,25–3× | Нет | Предпросмотр/модель |
| Реверс | Запись | Нет | Предпросмотр/модель; не перекодирование результата |
| Кадрирование и пропорции | Запись; пропорции также в руководстве | Есть свободная рамка и пресеты | Есть кадрирование; отдельный проектный раздел пропорций не завершён |
| Поворот/отражение/выравнивание | Запись | Только поворот кратно 90°; отражения/произвольного угла нет | Есть визуальные преобразования |
| Цветокоррекция и фильтры | Руководство, запись | Нет в VideoEditSpec и экспортной цепочке | CSS-приближения; не оригинальные Xiaomi LUT |
| Громкость, музыка, отделение исходного звука | Руководство: громкость/музыка; отделение — запись | Удаление звука и отдельный AAC/M4A; нет микширования или громкости | Панели/модель и локальный предпросмотр; отдельная выгрузка WAV |
| Надписи | Руководство и дополнительная запись | До 8 слоёв, реальные превью/экспорт, время появления каждого | Несколько слоёв; цвет/прозрачность/жирность/контур/тень/выравнивание/позиция/размер/поворот |
| Шрифты и подбор | Запись показывает только «По умолчанию» | Каталог 23 начертаний, пипетка, локальное распознавание текста образца и подбор похожего шрифта | Только показанный Default; наши расширения ещё предстоит включить в макет |
| Сохранение кадра | В изученных источниках для этого редактора не подтверждено | JPEG, с кадрированием/поворотом/активными надписями | Реальный PNG/JPG из canvas |
| Сохранение только аудио | В изученных источниках не подтверждено | Реальный AAC/M4A выбранного интервала | Реальный PCM WAV; формат отличается от приложения |
| Сохранение видео | Руководство подтверждает Save без точного диалога | Новая MP4-копия; прогресс, отмена, обработка при выходе с экрана | Честная заглушка ожидания образца; MP4 не генерируется |

## Доказательства в коде

- `app/src/main/java/com/domenota/medialoader/data/editor/VideoEditor.kt`:
  `VideoEditSpec`, `export`, `previewEffects`, `extractAudio` — trim, crop,
  поворот, removeAudio, текст; нет полей скорости, фильтров, переходов или микса.
- `data/editor/VideoFrameExporter.kt`: JPEG95%, ближайший кадр, crop/rotation/text.
- `data/editor/TextLayer.kt`, `TextLayerRenderer.kt`, `VideoTextOverlay.kt`:
  координаты, размер, угол, цвет, обводка, временной интервал; до 8 слоёв;
  `EditorFonts.all`: 7×3 + 2 = 23 начертания. Отдельных свойств тени,
  выравнивания, прозрачности в текущей модели нет; это нельзя считать готовыми
  native-возможностями только по HTML. Жирный/курсив доступны через шрифты.
- `ui/components/EditorTextDialog.kt`: пипетка, выделение образца,
  OCR/FontSampleMatcher, библиотека и временные интервалы.
- `ui/screens/VideoEditorScreen.kt`: кнопки реальных операций, рамка,
  временная шкала, переключатель звука, прогресс/отмена.
- `ui/MediaLoaderApp.kt` → `MediaLoaderViewModel.kt` →
  `data/editor/EditorExportCoordinator.kt`: подключённые операции экспорта,
  сохранение производных файлов через MediaRepository, фоновый сервис.

## Что сохранить и что потребуется для переноса макета

Сохранить наши 8 слоёв с интервалами, шрифты/подбор/пипетку, JPEG-кадр,
AAC/M4A и фоновый экспорт. Привести их к общей визуальной системе Xiaomi.
Расширить модель проекта и реальный экспорт для нескольких клипов, скорости,
реверса, фильтров/коррекции и аудиомикса. Отдельно сверить результат и превью.
Переходы/шаблоны из общего руководства не добавлять автоматически: их состав и
UI ещё не согласованы для пользовательского образца.

HTML v4 меняет только читаемость иконок. Этот аудит не означает, что перечисленные
недостающие Android-функции уже реализованы или полностью спланированы.
