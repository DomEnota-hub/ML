- Главная лента: Редактор, Музыка, Надписи, Соотношение сторон,
  Откорректировать, Фильтры; новые наши команды в конце и в меню⋮.
- Скорость с реальной показанной нелинейной шкалой0.25/0.5/1/2/3x,
  1x в центре, нижние X/название/✓.
- Коррекция: Тон/Цвет/Детализация;13регуляторов (выдержка, светлота, контраст,

  перемещение надписи. Стиль/Шрифт до новой записи не заполнены выдуманными панелями.

## Наши команды

- «Сохранить кадр»: PNG/JPG, настоящий Canvas download текущего кадра с
  доступными в HTML изменениями, текстом и кадрированием.
- «Извлечь аудио»: для открытого пользователем видео настоящее декодирование
  доступного браузеру аудио и экспорт выбранного исходного диапазона в PCM WAV.
  Это формат прототипа, не согласованная замена форматов Android-реализации.
- У встроенного кадра нет поддельной звуковой дорожки: для реального экспорта
  требуется открыть своё видео. Исходные пользовательские файлы не загружаются в сеть.

5. Полная сверка каталога фильтров: в записи видна только часть списка;
   длинная категория, предварительно названная «Кинематографический», требует
   подтверждения. Нельзя заявлять полноту названий/пресетов по текущему эскизу.
6. Многослойные надписи, точное изменение размера/поворота текста — после нового образца.

Это не финальная копия всех функций. Значения CSS коррекции и фильтров —
визуальные аппроксимации. Проприетарные LUT/математика не восстанавливаются из
записи. Реверс — модель/обратный предпросмотр, не кодирование новогоMP4.
Кнопка готового MP4 намеренно не скачивает JSON/другой файл под видом видео;
до дополнительной записи показывает ожидание образца.

## Как продолжить

Исходники index.template.html + editor.css + editor.js + assets.json.
`python3 build.py` создаёт один автономныйHTML. Воспроизводимые проверки требуют
уже установленного PythonPlaywright и `/usr/bin/chromium`; не повторять без причины.
Сборка на текущем workspace также лежит в `/workspace/medialoader-video-editor-v2`.
Не менять предыдущий основной HTML, где незакоммичены отдельные настройки/скрытые
разделы: они предшествовали текущей задаче и оставлены без вмешательства.
