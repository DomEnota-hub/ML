# v4 — читаемые иконки

Пользователь сообщил о размытых иконках. В v3 использовались SVG с тонкой линией
1,65px, несовпадающими размерами 24/25/29px и символы шрифта для Bold/Outline/Shadow.
Изменены: единая базовая сетка 24, линия 2px, явные квадратные размеры, векторные
глифы кнопок стиля/палитры, non-scaling-stroke, символ разрезания в виде скобок.
Иконки не используют растровые вырезки и внешние шрифты. Обычное сглаживание
диагоналей/кривых сохраняется. Лицевые особенности конкретной Xiaomi-версии по
каждому глифу пока не гарантируются.

Проверено: node --check обоих JS; короткий Playwright check_icons.py — отрисовка
клипа/Стиля при DPR2, все 6 значков стиля, работа переключателей,
ширина360px без горизонтального переполнения, нет JS errors. Снимки просмотрены.
Проверка запускает HTML через set_content: file:// блокируется политикой Chromium.
Android и полные прежние тесты не запускались. Для сравнения v3 читается соседняя
директория; без неё можно проверить только v4, изменив список версий в скрипте.

Сборка: python3 build.py → MediaLoader_video_editor_reference_v4.html,
170955bytes. Все ресурсы встроены. Видеофайлы остаются локально в браузере.
