# v7 — критерии фильтров, контуры иконок, живая обрезка, подписи

## Уточнения пользователя

Источник общего каталога фильтров — **наш макет фоторедактора**, не Xiaomi и не
текущий Android-код. Список/количество и последующие пополнения должны браться
из единого каталога фоторедактора. По просьбе «сохрани в HTML критерии» это явно
записано в раскрываемом блоке «Критерии для реализации» и JSON editorRequirements.
Текущий набор фильтров в HTML остаётся демонстрационным; фактическая синхронизация
не заявляется. Точного файла фоторедактора с базой здесь нет: локальные файлы и
ограниченный поиск Drive не дали такой каталог; не подменять выдуманным числом.

Вектора главного меню/клипа и части коррекции перерисованы вручную по контурам
14скриншотов из ../screenshots-drive-index.json. Основные изменения — одна нота
с флажком, скруглённая рамка T/пропорций, два регулятора, круги фильтров,
скобки разрезания, динамик с дугой, квадрат с play для реверса, скруглённые
копия/замена/отделение аудио, капля оттенка, зерно/чёрная точка/виньетка.
Размеры/толщина подогнаны к исходным пропорциям. reference-icons.json — источник
этих SVG, встроенный build.py в standaloneHTML. Нет растровых иконок/зависимости
от шрифтов. Полная пиксельная идентичность каждого оставшегося значка не обещается.

## Исправление обрезки

Причина: pointermove менял start/end, но сохранял позицию S.time, из которой
syncMedia выбирал прежний кадр. Конец первого клипа также мог разрешаться как
начало следующего через locate. Введён отдельный trimPreview выбранного источника
и граничного sourceTime; он обновляется во время перемещения обеих ручек.
Конец интервала показан с отступом1ms внутрь, чтобы не уйти за последний кадр.
Учтены скорость, реверс (обратное соответствие исходных границ), соседние клипы.
Предпросмотр сохраняется после отпускания ручки; seek/play/смена раздела/undo
сбрасывают граничный режим. Для настоящих кадров нужно открыть локальный видеофайл;
встроенный постер остаётся статичным.
