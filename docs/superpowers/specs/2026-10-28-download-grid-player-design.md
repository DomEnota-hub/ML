# Загрузки и управление видео

По запросу пользователя: переключатель списка и сетки из четырёх квадратных миниатюр без названий; маленькие значки музыки/видео справа снизу. В сетке нажатие открывает файл, удержание открывает существующее меню действий. Поиск, фильтры, папки и избранное сохраняются. Активные загрузки остаются информативным списком.

Выбранный вид запоминается. В сетке все файлы публикации видны отдельными миниатюрами; список сохраняет существующие группы. Сетка реализуется ленивыми рядами по четыре в существующем LazyColumn, чтобы не создавать вложенную прокрутку и сохранить ограниченную подгрузку миниатюр.

У миниатюр видео снизу тонкая полоса просмотренной доли. Источник — уже сохранённая позиция и длительность; новые просмотры сохраняют отдельную отметку прогресса, в том числе 100% после окончания, не меняя поведение возобновления. Для неизвестной длительности полоса не придумывается и файл ради неё не декодируется.

Смена формата показывает последнюю надпись поверх видео без Toast и очереди. Каждое нажатие заменяет надпись и перезапускает её таймер. Кнопки блокировки/разблокировки находятся у правого края по центру с безопасным отступом, вне нижней панели. Тап по заблокированному видео по-прежнему показывает/скрывает разблокировку.
