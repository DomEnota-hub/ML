# Проверка новых изображений в избранных сообществах VK

Пользователь задаёт начальную дату каждому избранному сообществу и одной кнопкой проверяет новые публикации. В результатах показываются только изображения. Пользователь выбирает файлы для загрузки; невыбранные изображения после завершения просмотра повторно не появляются.

## Поведение

- Начальная дата хранится отдельно у каждого избранного сообщества, существующим избранным по умолчанию назначается сегодня. Дату можно менять.
- Кнопка «Проверить публикации» запускает последовательное чтение стен избранных групп через сохранённый сервисный ключ. Одновременно выполняется одна проверка.
- Проверка читает порции до 100 публикаций и останавливается на отметке предыдущего завершённого просмотра или начальной дате. Изображения новых публикаций попадают в существующий экран результатов; рекламные остаются снятыми с выбора.
- Результаты сгруппированы по сообществам. «Завершить просмотр» сохраняет отметку проверки для этой группы. После этого все показанные изображения, включая невыбранные, не повторяются. Пустой успешный результат можно отметить просмотренным автоматически.
- При ошибке или прерывании отметка не меняется. Новые публикации, появившиеся во время проверки, остаются для следующей проверки.
- Скачивание остаётся ручным и использует существующий механизм. Журнал поиска сохраняет найденные задания.

## Подходы

Повторять существующий поиск за датой проще, но он перечитывал бы историю при каждом запуске. Выбран отдельный последовательный проход с отметкой времени последнего завершённого просмотра. Он уменьшает число запросов и сохраняет нынешний экран выбора и загрузки.

## Ограничения

- Видео и посты без изображений не показываются.
- Автоматической периодической проверки и автоматической загрузки нет.
- Результаты VK зависят от доступности стены и действительности сервисного ключа.
