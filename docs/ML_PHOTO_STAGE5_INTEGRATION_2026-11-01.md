## Защита пользователя
- Не сливать в релизную ветку и не подписывать production APK до ручной приёмки.
- Релизный application ID `com.domenota.medialoader`, versionCode, versionName, ключ DomEnota и оригинальные файлы пользователя не менять.
- Отладочная ARM64 QA-сборка с Gradle `-PhitmozArm64` имеет отдельный ID `com.domenota.medialoader.hitmoz` и может сосуществовать с установленным релизом. Её debug-подпись **не является релизной** и не гарантирует обновление предыдущих QA-APK.
- GitHub Actions сохраняет только один краткоживущий QA-артефакт, без копирования релизного ключа.

## Автоматическая проверка
1. Полный `app:testDebugUnitTest`, включая межэтапный smoke-тест последовательности Геометрия → Уровни/эффекты → Рисование.
2. `app:lintDebug`.
3. `app:assembleDebug -Parm64Release=true -PhitmozArm64=true`.
4. Проверка имени пакета, наличия подписи, хэша SHA-256 и архива APK для ручного теста.
