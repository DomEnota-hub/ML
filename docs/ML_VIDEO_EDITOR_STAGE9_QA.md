# ML · Видеоредактор · Приёмка этапа 9/9

Дата подготовки: 31.10.2026. Ветка: `feature/ml-video-editor-stage9-final-integration-20261031`.

## Что доказано CI, а что нет

Полные JVM/Robolectric-тесты проверяют состояние проекта, математические интервалы, скорость, порядок клипов, структуру Media3-композиции, аудиомикширование и политику проверки выходного MP4. Выполнение `assembleRelease -Parm64Release=true` доказывает компиляцию APK, но **не реальное кодирование** аппаратным видеокодеком, плавность на Android, реальный FPS или отсутствие артефактов.

На устройстве необходимо отдельно подтвердить:

- [ ] Видео 24/30/60 FPS, с разными размерами и ориентациями; ручная перемотка, пауза, последовательное воспроизведение, кадрирование.
- [ ] Три клипа из разных источников; разделить, изменить порядок, продублировать, удалить. Текст и переходы не смещаются неожиданно.
- [ ] Скорость ×0.25, ×0.5, ×1, ×2, ×4; исправные длительность, синхронизация аудио и подписи на стыках.
- [ ] Фотографии JPEG/PNG с прозрачностью/EXIF-ориентацией между видеоклипами, 0,5/3/30 с показа; смешанные портретные и альбомные материалы.
- [ ] Шрифты кириллицы, перемещение титров, 8 слоёв текста и 12 графических элементов; анимированные интервалы и эффект на границе клипов.
- [ ] Каждая из 5 склеек, спецэффектов и фильтров; предпросмотр сопоставить с итоговым MP4.
- [ ] Несколько звуковых дорожек: громкость, fade-in/fade-out, исходный звук + отсутствие исходного звука, без пропусков на фотографиях.
- [ ] Реверс (включая звук), отмена длительного экспорта, сворачивание приложения, возобновление и foreground-уведомления.
- [ ] Экспорт: исходное / 480 / 720 / 1080 / 2160p; 24/30/60 FPS; три качества; сравнить запрос с реальными метаданными MP4.
- [ ] Файл после экспорта доступен в библиотеке, воспроизводится внешним плеером, не обрезан и не повреждён. Неудачный экспорт не публикуется.
- [ ] Проверить маленький исходник, длительное видео, незаполненную/отозванную SAF-ссылку и нехватку места на устройстве.
- [ ] Регрессии вне редактора: главная, музыка, галерея, Instagram/YouTube/VK/RUTUBE, разрешения, корзина и фоторедактор.
- [ ] Сверить итоговый APK: ARM64-only; прежний `com.domenota.medialoader`, последовательное повышение versionCode и **тот же сертификат подписи**.

## Команды метаданных для итогового видео

```bash
ffprobe -v error -show_entries format=duration,bit_rate:stream=index,codec_type,codec_name,width,height,r_frame_rate,avg_frame_rate -of json exported.mp4
```

`METADATA_KEY_CAPTURE_FRAMERATE` на некоторых телефонах отсутствует. Отсутствующий параметр нельзя считать фактическими 30 FPS; для независимой проверки использовать `ffprobe` или медиаплеер с технической информацией.

## Важные ограничения

1. Media3 не выполняет полноценный crossfade между двумя потоками; реализованные переходы — через цвет/маску.
2. Аппаратный кодек вправе изменить запрошенные размер и битрейт; формально 60 FPS не добавляет отсутствующие реальные кадры.
3. Реверс использует дополнительное FFmpeg-кодирование; фактические характеристики могут отличаться от первого прохода.
4. HDR/SDR, EXIF, разные аппаратные декодеры, длинные материалы и Android 13–16 требуют QA на реальном устройстве.

## Подписание и выпуск (пока не выполнено)

1. После успешного CI и ручной QA зафиксировать релизную версию, проверить последовательность версий.
2. Убедиться, что защищённые GitHub Actions secrets `ML_RELEASE_KEYSTORE_BASE64`, `ML_RELEASE_STORE_PASSWORD`, `ML_RELEASE_KEY_ALIAS`, `ML_RELEASE_KEY_PASSWORD`, `ML_RELEASE_SIGNER_SHA256` соответствуют **существующему** ключу приложения. Генерация нового ключа нарушит возможность обновления поверх прежней установки.
3. Только после подтверждения QA разрешить ручной workflow `ML signed ARM64 release (manual QA gate)`. Проверить сертификат, `apksigner verify`, пакет, ABI, размер и SHA-256 полученного APK.
4. Сохранить подписанный APK в согласованное место и отдельно подтвердить установку поверх предыдущей версии; никаких автоматических публикаций в GitHub Releases.

**Никакие пункты device QA выше не отмечаются выполненными автоматически GitHub Actions.**
