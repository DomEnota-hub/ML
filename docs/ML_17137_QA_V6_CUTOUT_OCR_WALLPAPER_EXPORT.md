# MediaLoader — QA v6 · 06.11.2026

## Обратная связь (Android 16, Xiaomi)

1. «Выделить объект»: нужен режим **добавлять недостающие детали и стирать лишние области** маски.
2. «Текст с фото»: в оригинале белое слово с чёрной обводкой **«приветика»**, а Tesseract в 1.7.136 возвращает бессмысленные символы.
3. «Обои»: штатная галерея Xiaomi предлагает **«Экран блокировки / Рабочий стол / Оба»**, после выбора применяет без дополнительного подтверждения.
4. В диалоге вырезки три действия **«Копировать / Сохранить / Поделиться»** слишком низко; текст не белый и кнопки без рамок.

## Реализация в PR #60

- Неразрушающая кисть маски: Ластик / Вернуть, размер, мягкий край, отмена одного мазка, сброс, обработка только области касания.
- Координаты touch пересчитываются относительно ContentScale.Fit, иначе на фото с полями мазки смещались бы от пальца.
- Экспорт PNG из отдельного снимка актуальной маски; оригинал на диске не меняется.
- OCR: случайные разрозненные символы перестают приниматься за корректную строку; добавлен PSM_SINGLE_LINE на полосах снимка, русский и английский офлайн.
- Обои: собственный диалог с тремя целями и прямое применение через WallpaperManager.setBitmap после выбора. Для видео берётся неподвижный кадр.
- Три действия вырезки: белый текст, контур каждой кнопки, увеличенный нижний отступ.

## Проверки на устройстве

- «Вернуть» восстанавливает рукав, обувь и детали после U²-Netp; «Ластик» убирает лишний фон. Проверить жесты по краям, отмену, сброс и прозрачность сохранённого PNG.
- Кисть попадает под палец в портретной и ландшафтной ориентации на фото разной формы.
- Белые подписи и контур трёх нижних кнопок, панель не пересекается с системной навигацией.
- OCR на исходной фотографии с креветкой: ожидается **«приветика»**, а не только отсутствие мусора. Проверить также обычный русский и английский текст.
- Xiaomi: «Экран блокировки / Рабочий стол / Оба» применяются одним нажатием; проверить фото и кадр видео.
- Проверить функции ONNX, просмотрщика, копирования и отправки после изменений.

## Статус

Черновой PR #60, production не затронут. Автоматические проверки не заменяют ручную проверку Xiaomi Android 16.
