## Музыка

В режиме AUTO после завершения скачивания аудио запускается фоновая обработка
скачанного файла. Вначале распознаётся звук через Shazam даже при готовых
названии/исполнителе источника. При совпадении используется результат Shazam,
включая URL обложки; существующий Mp3MetadataWriter загружает и встраивает её
в MP3, а после записи сбрасывается локальная миниатюра. Результат сохраняется
в истории, в том числе recognitionArtworkUrl для удалённого запасного пути.

Если совпадения нет, используются данные источника. При исключении Shazam или
декодирования и наличии метаданных также используется источник; отмена не
перехватывается. При ошибке без метаданных файл остаётся скачанным, ошибка
постобработки записывается в журнал.

Удалены несовпадающие списки провайдеров в onCompleted/processDownloaded:
автоматическая обработка охватывает все скачанные аудио, включая Muzmo.
В sourceMetadata добавлен Muzmo для запасного пути.

Автоматическая обработка сериализована семафором (1), чтобы пачка скачанных
треков не запускала декодирование/перезапись MP3 параллельно. Скачивание не
ожидает эту обработку. MANUAL/OFF не запускают Shazam автоматически.

Ограничения: доступность обложки зависит от распознавания и сети; при ошибке
встраивания действует прежний запасной путь записи тегов без обложки. Старые
треки массово не перераспознаются. Реальные ответы Shazam на устройстве не
проверялись; тесты используют контролируемые ответы на границе сервиса.
