# MediaLoader 1.7.40 (102) — Instagram post backdrop

The browser now applies empty backdrop recovery to Instagram post and Reel pages as well as profile pages. When a visible post dialog is present, it preserves the dialog and removes only the covering backdrop. RUTUBE browser sign-in behavior from 1.7.39 remains available.

The Instagram profile feed search still fails on the user's device: its web request requires access and its fallback gets HTTP 400. This visual update does not alter that network path.
