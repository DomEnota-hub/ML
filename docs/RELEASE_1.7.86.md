# MediaLoader 1.7.86 — одиночный выбор видео / аудио

- В окне без фотографий варианты видео и аудио используют RadioButton: точка в круге.
- Тот же вид и правила выбора применяются в шапке предпросмотра.
- Выбор аудио снимает выбор видео и наоборот. Повторное нажатие выбранного варианта
  сохраняет его выбранным.
- Начальный выбор без фото ограничен первым подходящим вариантом, чтобы несколько
  видеовариантов не отображались выбранными одновременно.
- В публикациях с фото сохранён независимый выбор; для аудио такой публикации
  применяется круглый индикатор с галочкой, который можно снять.
- Логика вынесена из ViewModel в togglePreviewSelection и покрыта тестами:
  взаимное исключение, повторное нажатие, начальный одиночный выбор, независимость фото.

Проверка: RED воспроизведён для снятия выбранного радио и для нескольких видео по умолчанию.
