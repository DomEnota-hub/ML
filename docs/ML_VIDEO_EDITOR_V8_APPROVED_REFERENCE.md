# MediaLoader · Video editor v8 — утверждённый контракт UI/UX и функциональности

Дата утверждения: 2026-11-02. Статус: **APPROVED REFERENCE / IMPLEMENTATION IN PROGRESS**.
Этот документ заменяет визуальную часть прежнего ТЗ видеоредактора. Старый Android UI не служит ориентиром.

## Источники истины (приоритет)
1. **HTML v8**: `MediaLoader_Видеоредактор_v8_две_строки.html` — https://drive.google.com/file/d/1mysfXrzXaD5B-Nqxk76aWyEpIPaeXztQ/view
2. **Скриншоты**: Google Drive → «Образцы » → «Основное меню» — https://drive.google.com/drive/folders/1vmekpotCut9F_NZn-OVQxqfyn1IVj4AJ. Из корня берём главную компоновку, из дочерних каталогов («Редактор», «Музыка», «Надписи», «Соотношение сторон», «Откорректировать», «Фильтры») — соответствующие экраны.
3. **Записи поведения**: Google Drive → «Образцы » — https://drive.google.com/drive/folders/1_gYKLDtiT0Krtv2SwAYLjnoAK3_oA07q; основное видео `Видео` и три записи Screenrecorder. Видеозаписи уточняют тач-взаимодействия, времена и переходы, которых не видно на статических кадрах.
4. **Каталог фотофильтров**: `PhotoEffect` + `PhotoEffectCatalog` в `data/editor/PhotoColorAdjustments.kt` (основан на НАШЕМ HTML-макете фоторедактора, не на Xiaomi). Каталог **единый**, а не скопированный вручную в enum видео.
5. **Имеющаяся функциональность ML**: сохраняется независимо от визуальной перестройки; ниже перечислены обязательные совместимые сценарии.

## Глобальная компоновка (эталон: 390 × ~867 CSS px)
- Чёрная рабочая поверхность #101010; основной акцент #ffc000. Без цветных «пилюль» старой двухуровневой навигации.
- Верхняя строка: закрыть, «Сохранить», вертикальное меню. Отмена/повтор — рядом с управлением воспроизведением, а не произвольно в заголовке.
- Центральный предпросмотр вписывается в свободное место с учётом вертикального/горизонтального видео, реальных сторон и системных insets; кадрирование строго внутри реальных границ изображения.
- Управление воспроизведением, время и горизонтальные дорожки клипов; позиционный указатель ограничен высотой дорожек.
- **Одна** нижняя горизонтально прокручиваемая лента главных инструментов, именно в порядке v8: «Редактор», «Музыка», «Надписи», «Соотношение сторон», «Откорректировать», «Фильтры», «Ещё». Нижняя подпись полностью читается.
- Вложенный экран открывает ленту подраздела с кнопкой возврата к главной; никакого прежнего второго ряда «Монтаж / Оформление / Звук / Файл».
- Для «Соотношение сторон» надпись **в ровно две строки**: «Соотношение» / «сторон». «Откорректировать» полностью, при необходимости перенос на две строки без потери букв. Карточки коррекции никогда не обрезают подписи снизу.
- Контуры, размеры, пропорции и глифы всех значков сопоставляются с одноимёнными скриншотами, не заменяются одинаковой общей пиктограммой.

## UX и работа эффектов
- Изображения фильтров/эффектов = **разные реальные превью кадра с применённым алгоритмом**, а не AutoAwesome или одинаковые заглушки. Кэш превью, без тяжелой обработки при каждом скролле.
- Все фильтры из `PhotoEffectCatalog` доступны фото и видео; новые элементы появляются в обоих без дублирования enum и без отдельного ручного копирования списка.
- Для каждого фильтра: категория, название, превью, сила 0–100%, сброс. Фактический алгоритм должен совпадать в предпросмотре и MP4. Если функция недоступна в Media3, сначала делается поддержка или явно ограничение; нельзя показывать фиктивно работающий эффект.
- Параметры «Откорректировать» и подписи воспроизводят скриншоты из папки; выбранный ползунок изменяет изображение вживую, применённые значения не исчезают при навигации.
- Обрезка: при перемещении ЛЕВОЙ ручки в предпросмотре соответствующий будущий первый кадр; при перемещении ПРАВОЙ — будущий последний кадр; виден без подтверждения, результат совпадает с экспортом. Отдельный свайп по дорожкам прокручивает позицию.
- Временная шкала не выходит за экран, position line обрезается по дорожкам и корректно реагирует на дополнительные аудиодорожки.

## Экран «Надписи»
- Одновременно до 8 независимых текстовых слоёв; свой начальный/конечный таймкод для каждого.
- По образцу вкладки клавиатуры, стиля и шрифта. Контур, тень, жирность, выравнивание, цвет, пипетка, библиотека шрифтов.
- Прозрачность конкретного слоя 0–100%; предпросмотр и экспорт одинаковы. Перемещение/масштаб/поворот и выбор слоя.
- Нельзя терять готовые текстовые слои при смене вкладки, клипа или возврате к главному меню.

## «Ещё» в КОНЦЕ главной ленты
- «Сохранить кадр» → JPEG, корректный кадр при текущем таймкоде, независимый вывод.
- «Извлечь звук» → AAC/M4A, прогресс/отмена и существующая фоновая обработка.
- Остальные уникальные возможности ML допускаются в этом подразделе при сохранении исходных сценариев, но не должны вытеснять две обязательные операции.

## Сохранение
- Как на скриншоте: затемнение редактора, снизу округлённое окно, сообщение, числовой %, **синяя** полоса прогресса.
- MP4-копия; исходный файл не перезаписывается. Обработка в фоне с ForegroundService/WorkManager как сейчас; отмена, уведомление, корректные ошибки и результаты.
- Никаких демонстрационных процентов в APK: только прогресс реального задания. HTML v8 остаётся интерактивным макетом, не кодирует MP4.

## Невозможные компромиссы
- Нельзя заменять реальный алгоритм эффектов чисто декоративными карточками.
- Нельзя выдавать «CI зелёный» за доказательство visual parity.
- Не смешивать фильтры из Xiaomi с собственным `PhotoEffectCatalog`.
- Не обрезать шрифты/лейблы, не давать ручкам кадрирования выходить из видео.
- Production и прежний QA Releases не изменяются до отдельной ручной приёмки.

## Порядок инкрементальной реализации и контроль качества
1. **V8 Navigation/layout**: один корневой док, вложенные ленты, корректные insets и рендер длинных лейблов; сравнение главного экрана и «Редактор» со скриншотами.
2. **Timeline/preview**: ограничение playhead, двусторонний live-trim, жесты, кроп по геометрии; тесты границ и сверка с записью.
3. **Filters**: общий источник PhotoEffectCatalog, математика shader-предпросмотра/экспорта, разные реальные thumbnails; тесты всех категорий, изменения цвета и наличия пиксельного эффекта.
4. **Adjustment/effects**: все контролы и узнаваемые миниатюры эффектов; сравнение каждого вкладки и сохранения.
5. **Text & music**: 8 слоёв, время, пипетка, opacity, шрифты, аудиодорожки; синхронизация, сравнение вложенных папок.
6. **«Ещё» + export**: JPEG/AAC/MP4 с честным окном прогресса, отменой, фоновым заданием; integration end-to-end.
7. **Final parity gate**: снимки на Android одинакового размера с reference, визуальный diff/проверка размещения плюс ручной сценарный QA. Тесты, lint, ARM64. Только отдельный prerelease после успеха, без изменения production.

Перед каждым PR проверяется матрица: **HTML v8 → скриншот папки → видеоповедение → фактический Android UI → API/экспорт → тест**. При провале одного измерения соответствующий пункт не считается завершённым.
