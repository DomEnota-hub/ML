# MediaLoader 1.7.84 — повторы автоматического получения Instagram

Причина: в журнале 27 октября в 22:45, 22:53, 23:00 и 28 октября в 08:41
получение публикации завершалось UnknownHostException ещё до создания очереди.
Worker возвращал failure и больше не запускался.

## Изменения

- WorkManager ожидает CONNECTED перед получением публикации.
- DNS, timeout, ошибки соединения/socket и TEMPORARY_FAILURE провайдера возвращают retry.
- Максимум пять запусков получения; exponential backoff 30, 60, 120, 240 секунд.
  Планировщик Android может увеличить фактическое время ожидания.
- Нет сети при постановке ссылки: уведомление об ожидании подключения.
- Временный сбой: уведомление об отложенной загрузке и номере следующей попытки.
- ACCESS_REQUIRED, UNSUPPORTED, RATE_LIMITED, TLS, файловые ошибки не повторяются.
- CancellationException распространяется без перехвата.
- Retry-политика охватывает только repo.resolve, до repo.enqueue. Ошибки последующих
  операций не вызывают новый автоматический resolve/enqueue из этой политики.
- Идентификаторы очереди стабильны для WorkRequest + media identity: остановка
  и перезапуск по сетевому ограничению не дублируют уже добавленные строки.
- Сохранены KEEP для одинаковой ссылки и проверка уже скачанных файлов.
- Уведомления учитывают пользовательские настройки и разрешения Android.

## Ограничения

Ранее завершившиеся failure задачи не оживут после обновления: ссылки нужно отправить
повторно. Повторы не устраняют длительную недоступность DNS/VPN/Instagram. Сбои уже
идущей передачи обслуживаются существующей очередью, эта правка касается получения
публикации. Реальное фоновое поведение Xiaomi требует проверки на устройстве.

## Проверка

InstagramAutoShareRetryTest: DNS → повтор → успех; предел пяти запусков;
connection/temporary provider; отсутствие повторов для постоянных ошибок и отмены.

Итог: testDebugUnitTest + assembleRelease -Parm64Release — BUILD SUCCESSFUL.
514 тестов: 513 прошли, 1 пропущен, 0 ошибок/падений. Release lint vital пройден.
Регрессии DNS и дубликатов проверены RED → GREEN.
