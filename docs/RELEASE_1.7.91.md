# MediaLoader 1.7.91

- В «Загрузках» добавлен переключатель списка и сетки. Выбор запоминается.
- Сетка: четыре миниатюры в ряд без названий. Видео и музыка отмечены маленьким значком справа снизу. Нажатие открывает файл, удержание — меню действий (папки, избранное, переименование, перенос в личное и другие прежние действия).
- В сетке фотографии из публикаций показываются по отдельности; список сохраняет группировку. Поиск, фильтры и папки работают в обоих видах. Активные задачи остаются списком с состоянием скачивания.
- У миниатюр видео появилась тонкая полоса просмотренной доли, включая полностью просмотренные ролики. Используются сохранённая позиция и длительность, без декодирования видео ради полосы. Для старых роликов с неизвестной длительностью прогресс появится после открытия видео.
- Режим вписывания/растяжения показывается поверх видео. Новое нажатие сразу заменяет надпись и перезапускает таймер; очередь системных уведомлений больше не используется.
- Блокировка и разблокировка управления расположены у правого края по центру в обычном и полноэкранном режиме.

## Проверка

Проверены сетка из четырёх равных ячеек с неполным последним рядом, отсутствие подписей, открытие файла и меню, сохранение вида, чтение старой позиции, окончание просмотра, неизвестная длительность и смена формата с отменой старого таймера.
