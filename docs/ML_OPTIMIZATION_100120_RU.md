# Оптимизация после журнала100120

Работа в существующей ветке PR54; функции обработки/экспорта и исходные файлы сохранены.

## Изменения
- Кэш кадров проекта: LRU8МиБ, абсолютные позиции исходника с шагом500мс для миниатюр, размер/ориентация плитки и ревизия источника. Границы обрезки не входят в ключ. При полном попадании исходник не открывается повторно. Старую ленту сохраняем при догрузке, при первом открытии публикуем готовые плитки постепенно. Кэш закрывается вместе с проектом. Вытеснение не recycle-ит Bitmap, который ещё рисует Compose; лимит относится к ссылкам LRU, не ко всей памяти приложения/видеодекодера.
- Нативное извлечение миниатюр и граничных кадров проходит через общий справедливый семафор, захватываемый на отдельный кадр, а не на всю пачку. Качество миниатюр и точность граничных кадров не снижались. В журнале теперь видны cacheHits/cacheBytes.
- Положение полосы интерполируется по кадровому такту внутри таймлайна с ограничением экстраполяции150мс. Корневой экран не переводится на60обновлений/с. Это не утверждение о фактическом FPS декодера.
- Журнал100120: Detaching surface timed out → SurfaceView.surfaceDestroyed/setVideoOutputInternal. Для SDR наAPI30+ используется TextureView; перед уходом экрана preview останавливается, при возвращении подготавливается, AndroidView явно отсоединяет плеер при освобождении. Для обнаруженного HDR и старыхAPI оставлена прежняя поверхность; параметры экспорта не менялись. Устранение тайм-аута и корректность изображения/HDR на реальном устройстве пока НЕ ПОДТВЕРЖДЕНЫ.
- Индексы псевдонимов, строк медиатеки и назначений альбомов готовятся на Dispatchers.Default. Во время обычного обновления сохраняется допустимый прежний снимок, при смене приватного доступа старый снимок скрывается синхронно. Состояние готовности учитывается в маршрутах телефонных файлов, чтобы ожидающий индекс не считался удалением файла. Вычисления выполняются в согласованном Compose Snapshot, устаревшая работа отменяется.
- Кандидаты просмотрщика запоминаются по входам вместо повторного merge/copy всего каталога при каждом обновлении экрана.
- Обычные уведомления MediaStore накапливаются во время фото/аудио/видеоредактирования; обработка возобновляется после выхода. Уже запущенный scan не обрывается. Явный refresh, изменение разрешений и обработка приватности остаются непосредственными. Загрузки, экспорт и фоновое воспроизведение не отключались.
- Категория «Популярное» убрана из видеофильтров, выбран «Все». Все фильтры/эффекты каталога сохранены. Новая векторная иконка эффектов, обновлённый контур «Разделить звук» по образцу.

## Проверки и ограничения
Первый выбранный запуск:21тест,20PASS,1тайм-аут нового BackgroundLibraryProjectionTest после изменения приватного доступа. После явного снимка состояния и синхронизации UI теста отдельный запуск BackgroundLibraryProjectionTest + EditorItemsProjectionTest PASS (4м09с с компиляцией). Остальные проверки кэша/поверхности/очереди/жестов/каталога ранее прошли; весь набор повторно не запускался. Ошибки компиляции при сборке иконок/импортах/типе ключа исправлены. Точный итоговый исходный код дополнительно компилируется CI доставки.

Локального Android-устройства нет. Нативные приостановленные кадры, жизненный цикл на Xiaomi Android16, субъективная плавность, память и число сканирований при редакторе требуют проверки следующего APK. Не объявлять ошибку или все лаги исправленными только по JVM-тестам. Полная матрица реального MP4/кодеков и полный lint не повторялись; изменения экспортного движка отсутствуют.

Оставшиеся кандидаты после замера: общая фильтрация/группировка галереи, холодная инициализация контроллеров, дальнейшее уменьшение промежуточных объектов. Не отключать функции и проверки доступа ради чисел FPS.
