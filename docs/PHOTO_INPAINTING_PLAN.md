# Photo inpainting — подготовка MediaLoader 1.6.8 для версии 1.7.0

## Текущее состояние
- Действующий редактор `PhotoEditor` выполняет обрезку, повороты и отражения; сохранение координирует `EditorExportCoordinator`.
- В 1.6.8 добавлены только контракты `ImageInpaintingEngine`, `MaskStroke`, `MaskPoint`, `InpaintingSettings`.
- Никакие ML-модели, бинарные библиотеки, новые разрешения или кнопки в интерфейс версии 1.6.8 не добавляются. Размер базового APK от AI-модели не возрастает.

## Предлагаемая архитектура
1. Выделение области на слое редактора. Координаты нормализованы 0..1 относительно исходного изображения; кисть допускает несколько штрихов.
2. Локальная подготовка рабочей копии фото; оригинал не изменяется. Для больших фото — масштабирование до поддерживаемого моделью рабочего размера с контролем RAM.
3. Преобразование штрихов в бинарную маску; выбор движка.
4. Вычисление вне UI-потока с поддержкой отмены; кнопка «До/После».
5. Подтверждение и сохранение результата как нового файла штатным экспортным механизмом редактора.
6. Опциональная установка весов модели только при первом использовании (после согласия пользователя), проверка SHA-256 и наличия свободного места. Отказ или отсутствие сети не должны ломать обычное редактирование.

## Кандидаты
- OpenCV inpaint: быстро для маленьких текстовых областей и простых структур; качество крупных объектов ограничено.
- LaMa: кандидат для нейросетевого inpainting; требуется отдельно проверить подходящий вес модели, лицензию конкретных артефактов, преобразование под Android и производительность ARM64.
- ONNX Runtime Mobile / другие локальные рантаймы: выбор после профилирования, а не заранее.

## Измерения на устройстве
- Фотографии 720p, 1080p, 4K; разные маски 1%, 10%, 30%.
- Пиковое потребление памяти, время обработки, аккумулятор и размер зависимостей.
- Качество на тексте, сложных текстурах, лицах и повторяющихся узорах.
- Отмена операции, поворот экрана, недостаток места, отсутствие интернета, возврат в редактор.

## Стоп-условия
Не добавлять AI-редактор в стабильную сборку 1.6.8. Интеграция отдельным этапом 1.7.0 и только после испытаний на ARM64, оценки лицензии и размера модели.
