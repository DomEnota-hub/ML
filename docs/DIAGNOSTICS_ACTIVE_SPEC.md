# Диагностика для разработки после 1.7.7

Согласовано в чате 21.10.2026. Диагностика должна различать косвенное наблюдение и фактический запуск рабочего сценария.

## Режимы

- Быстрая проверка оставляет лёгкие локальные и анонимные сетевые пробы. Открытие экрана ничего не запускает.
- Полная проверка запускается явно, может использовать сохранённые сессии, выполнять поиск и извлечение метаданных, проверять локальные runtime-компоненты и пробную запись. Для источников принимаются контрольные ссылки и поисковый запрос; отсутствие тестовых данных отображается как «Не запускалась».
- Ни один результат одного HTTP-запроса к главной странице не объявляет исправной или сломанной загрузку. HTTP 403, редирект и тайм-аут анонимной пробы описывают только ограничение этой пробы и не создают неисправность загрузчика.
- Активные пробы не затрагивают пользовательские загрузки. Временные данные удаляются. Отмена диагностики не отменяет пользовательскую очередь.

## Представление

- Во время запуска строки имеют состояния «Ожидает», «Проверяется» или завершённый результат. Результат текущего запуска не считается устаревшим, включая изменение системного времени во время пробы.
- Фиолетовый цвет отмечает фактически выполняемую проверку или раздел; раскрытие карточки не влияет на её статус.
- Счётчик «Получены результаты» и число фактически подтверждённых функций разделены. Косвенные и исторические сведения показывают свою область доказательства.
- После завершения сохранённый прогон может устареть по отдельным правилам. Предыдущий и текущий прогоны не смешиваются.
- Отчёт указывает этап, который реально был выполнен, и предел вывода; не включает сессии, ссылки, пользовательские запросы и временные файлы.

## Приёмка

- При прогрессе 18/26 новые строки не показывают «Устарело», а подсветка относится только к текущему этапу.
- Для 3xx, 403 и тайм-аута анонимной пробы не появляется подтверждённая неисправность рабочего источника.
- Наличие библиотеки, cookie или старой загрузки само по себе не даёт успешную проверку функции.
- Полный режим демонстрирует запуск локальных библиотек, проверку выбранного хранилища и рабочий сценарий источника при наличии контрольных данных; отказ точно указывает неудавшийся этап.
- Сетевой тайм-аут ограничен на уровне запроса; остановка проверки остаётся отзывчивой.

## Уточнения по проверке 1.7.8

- Число выполненных проб отделено от числа подтверждённых этапов. Общий итог полной проверки не может быть зелёным, если рабочее получение метаданных или проверка сессии источника не подтверждены.
- Полная проверка оценивает сессию отдельным запросом к аккаунту. Наличие cookie-файла не считается доказательством входа; неоднозначный ответ не удаляет сессию и не объявляется выходом из аккаунта.
- Отчёт показывает длительность каждой пробы и безопасную причину отказа. Для VK и RUTUBE требование входа отличают от временной ошибки и недоступного материала.
- Для резервного музыкального поиска отдельно ограничены ожидание страницы и ожидание результатов.
- Встроенный браузер VK регистрирует схему заблокированного перехода и безопасно переводит доверенный QR-переход на HTTPS. Если продолжить вход невозможно, экран сообщает об этом вместо молчаливого отказа.
