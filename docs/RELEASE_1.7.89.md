# MediaLoader 1.7.89

Выпуск ранее подготовленных изменений по запросу пользователя.

## LaMa

- Обработка участка вокруг выделения с запасом контекста вместо растяжения всего кадра.
- Пропорции изображения и маски сохраняются; отражённые области маски соответствуют изображению.
- Небольшое расширение маски и внешняя растушёвка краёв, сохранение мелких выделений при уменьшении.
- Исправлены остатки маски после ластика и повторное смешивание краёв при экспорте.
- Новая иконка ластика вместо Backspace.

## Instagram

Длинный ответ об ограничении публикации теперь разбирается до сокращения записи в журнале.
Ограничение чувствительного контента получает понятное сообщение вместо временной ошибки.
Само ограничение аккаунта приложение снять не может.

## Проверка

Геометрия, отражённые маски, композиция/экспорт и разбор длинного ответа Instagram
покрыты регрессионными тестами. Реальное качество предсказания модели и работа на
физическом устройстве требуют проверки после установки.
