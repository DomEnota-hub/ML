# MediaLoader 1.7.88 — перемешивание музыки

Рядом с повтором добавлена иконка Shuffle в IconToggleButton. Включённый режим
подсвечивается основным цветом, имеет toggle semantics и описание «Перемешать».

Кнопка меняет shuffleModeEnabled у MediaController фоновой AudioPlaybackService.
Новый список не создаётся, текущие mediaId/позиция не меняются. Media3 отвечает за
случайные переходы, включая конец трека и команды следующего/предыдущего трека
из полного плеера, мини-плеера и системной сессии. Выключение возвращает обычный
порядок; исходная последовательность mediaItems сохраняется.

UI получает начальный shuffleModeEnabled при подключении и синхронизирует его
через Player.Listener.onShuffleModeEnabledChanged. Состояние живёт в фоновой
сессии, без отдельного сохранения на перезапуск процесса. Повтор очереди/трека
сохраняет стандартное поведение Media3.

Проверка: AudioPlaybackModesTest использует реальный ExoPlayer и заранее
заданный shuffle order. Нажатие включает флаг, меняет следующий индекс;
переходы вперёд/назад следуют ему. Исходный список и позиция текущего трека при
переключении не меняются; выключение восстанавливает последовательный переход.
RED: тест падал при отсутствии кнопки.
