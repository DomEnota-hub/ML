# MediaLoader · Photo Cutout on Android 16 · 5 ноября 2026

## Источник и подтверждённые симптомы
Экспорт журнала `MediaLoader_1.7.134_logs.md` (Android 16, Xiaomi 24116RACCG):
пять нативных аварий `NATIVE_CRASH` / `status=11` сразу после
`PhotoCutout: Subject segmentation module ready`, без Java stack trace.

Публичный [отчёт ML Kit #1017](https://github.com/googlesamples/mlkit/issues/1017)
описывает SIGSEGV в `drishti_gl_runn` при вызове
`play-services-mlkit-subject-segmentation:16.0.0-beta1` на Android 16.
Это **сильное совпадение**, но без tombstone с телефона нельзя доказать,
что в данном экземпляре падения тот же самый поток / MTE fault address.

Ожидание установки Google Play-модуля не решает проблему аварии
во время нативного inference: SIGSEGV нельзя перехватить `try/catch`.

## Реализация (в отдельной ветке, НЕ production)
На Android 16 (API 36+) ни подготовка, ни `process()` библиотеки
Subject Segmentation не вызываются. Вместо них ONNX Runtime CPU
(уже существующая зависимость приложения) выполняет U²-Netp.
Исходная фотография **никогда не загружается на сервер**.
При первом использовании скачивается только ONNX-модель (~4,6 МБ).
Файл сохраняется в `filesDir/cutout-models`, затем используется офлайн.

Проверка загрузки: фиксированные размер 4574861 байт и SHA-256
`309c8469258dda742793dce0ebea8e6dd393174f89934733ecc8b14c76f4ddd8`.
Неверные/неполные файлы не запускаются, временные части удаляются.

U²-Netp делает **одно совмещённое выделение переднего плана**.
Покадровое выделение нескольких независимых предметов, доступное через
ML Kit, этим движком не поддерживается: интерфейс показывает только
«Все объекты». Это сознательное функциональное ограничение до выбора
надёжного многосубъектного алгоритма для Android 16.

Для API 35 и ниже прежняя работа ML Kit сохранена без изменений.
PNG-иконки, меню и иные UI-замечания версии v10 в этой ветке не правились.

## Модель, атрибуция и источники
- U²-Net: Xuebin Qin et al., Pattern Recognition 2020
- Исходный проект: https://github.com/xuebinqin/U-2-Net
- ONNX-экспорт: https://github.com/danielgatis/rembg
- Публичное зеркало: https://huggingface.co/Heliosoph/u2net-onnx
- Указанная лицензия зеркала: Apache-2.0; исходный код rembg: MIT.
- Проверить для коммерческой публикации отдельно условия распространения
  исходных обученных весов: код и веса могут иметь разные условия.

## Обязательная ручная проверка перед выпуском
- Android 16: несколько запусков «Вырезка фото» подряд, 0 native crash.
- Android 16: фотография с одним предметом, несколько предметов, мелкие детали,
  прозрачный фон PNG, EXIF-повороты, крупная фотография.
- Повторное использование в авиарежиме после первой успешной загрузки модели.
- Прерывание скачивания модели, невозможность получить файл, неверная
  контрольная сумма, мало места.
- Отмена операции и повторное открытие. Экспорт PNG, копирование и отправка.
- Android 14/15: прежняя многосубъектная ML Kit ветка не деградировала.
- По возможности получить native tombstone от старой версии 1.7.134
  и подтвердить конкретную библиотеку из `backtrace`.
