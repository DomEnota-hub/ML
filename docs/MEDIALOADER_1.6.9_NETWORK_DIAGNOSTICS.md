# MediaLoader 1.6.9 (49): сетевая диагностика и пояснения

База: MediaLoader 1.6.8, коммит `1653d32af5ca1b5a08417fb7cff949b22615e9ea`.

## Причина изменений
Контрольные испытания на мобильном интернете показали:
- без VLESS: повторяющиеся `Search watchdog expired` через 20 секунд, без результатов поиска;
- с VLESS: HitMoz сумел выдать пять результатов, а `Damage — STEAL MY HEART` успешно скачалась через `s1.deliciouspeaches.com`;
- в более раннем журнале Cronet показал `ERR_NAME_NOT_RESOLVED` при обращении к `cdn12.deliciousoranges.com`, а Android HTTP — `SocketTimeoutException` и `Connection reset`.

Связь не доказывает блокировку или неисправность конкретного CDN. Приложение не меняет маршрутизацию VPN.

## Изменения
- Классификатор `HitMozNetworkFailure` различает DNS, тайм-аут, сброс и остальные ошибки, включая обфусцированное исключение Cronet по коду `ERR_NAME_NOT_RESOLVED`.
- В расширенном журнале фиксируется `reason` без исходных URL, токенов или секретов.
- Временная статистика неисправности CDN учитывает только сетевые причины, а не HTTP-ошибки и отказы формата.
- Когда все попытки одинаково завершились сетевой ошибкой, пользователь видит соответствующее безопасное объяснение.
- В русском журнале есть отдельные описания DNS/RESET/TIMEOUT и пояснение незавершённой загрузки WebView.
- `[WARN] [HitMoz] Search watchdog expired` выделяется красным в просмотре даже при стандартном техническом уровне WARN. Другие WARN остаются оранжевыми.
- Объяснение для `Search watchdog expired` также красное, когда включено отображение пояснений.

## Ограничения
- Журнал не содержит DNS-пакеты, поэтому нельзя доказать, какая конкретно сеть/резолвер вызвали ошибку.
- Базовый `ru.hitmoz.org` может быть недоступен вне VPN; повторные запросы не устраняют ограничения сети.
- Альтернативные адреса CDN должны поступать от HitMoz; приложение их не конструирует.
