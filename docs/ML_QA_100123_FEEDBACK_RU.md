# QA после обратной связи по 100122

Продолжение PR #54 с HEAD ece7f9b42c7bac553f69c5dbf81fbfd54335626d.

## Аудио — приоритет P0

В предпросмотре разделение автоматически создавало дополнительный ExoPlayer и коррекцию его позиции. Теперь отделённый исходный звук, пока его время совпадает с видеоклипом, воспроизводится родным видеоплеером. Полоса остаётся самостоятельной редактируемой моделью. Обрезанный диапазон, громкость и fade применяются к громкости этого плеера. Перемещённая или ускоренная независимо дорожка использует отдельный плеер. Экспорт по-прежнему использует существующую модель отдельных дорожек с отключённым оригиналом; оптимизация только предпросмотра не меняет проект и экспорт.

Ручки аудио считали перемещение в своих движущихся локальных координатах. Расчёт переведён в координаты корневого окна; одинаковые значения не записываются повторно. Указатель аудио закреплён в центре так же, как указатель видео.

Статус: PARTIAL / NOT_DEVICE_TESTED. Реальное воспроизведение, серия обрезок/seek и MP4 с проверкой звуковой дорожки требуют устройства. Новые функции маршрутизации покрыты адресным JVM-тестом; это не проверка слышимой синхронизации.

## Музыка

«Мои плейлисты» сверху, папки ниже. Отображается последнее имя пути; внутренний полный ключ сохраняется для различения папок и существующих исключений. Имена папок/треков используют onSurface (белый в тёмной теме, читаемый тёмный в светлой), треки имеют миниатюры. Обнаружено принудительное масштабирование кадра в 144×94. Заменено пропорциональным заполнением карточки с центральной обрезкой. Горизонтальные и вертикальные кадры не должны искажаться.

## Корзина

Для файлов телефона в обработчике нажатия стоял явный запрет. Добавлен отдельный просмотр изображения/видео без восстановления. Для изображений — ограниченное декодирование вне UI-потока, для видео — существующий LocalVideoPlayer. Если системный провайдер запрещает чтение удалённого файла, доступ нельзя подтвердить без устройства; ошибка отображается пользователю.

Переключатель список/сетка общий для двух вкладок. Выбор файлов отделён от открытия, восстановление/удаление используют прежние обработчики и системное подтверждение.

Сортировка приложения — по времени изменения приватной копии, созданной при удалении. Сортировка телефона — по DATE_EXPIRES убыванию, с DATE_MODIFIED при отсутствии значения. Android не предоставляет здесь отдельную точную дату удаления; порядок по сроку хранения приблизителен при разных сроках хранения. Файлы телефона не восстанавливаются для просмотра.
