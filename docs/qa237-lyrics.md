Local first: read-only ID3v2.3/v2.4 USLT/SYLT subset (milliseconds only), LRC sidecar for directly accessible file URIs, explicit SAF import for content URIs. Unsupported tag formats must not be guessed or rewritten. Imported lyrics are stored in no-backup app storage under a hash of source URI, size and modified time; no shared source writes. Current AudioBookmarkAdmission, recovery/permission/identity fences and readable source are mandatory; privacy moves remove matched records under the shared guard, uncertain records are discarded. File sidecar may also be resolved via a proven file-stat alias of a MediaStore row. No lyrics corpus ships in the app; tests use invented fixtures.
