# ML 1.7.194 / 254 — цикл 1, этапы 1–2

База: выпущенная QA 1.7.193, remote SHA `951f1753576c247ee8a3e8ed2ace6ed56e47dba2`. Черновой Cache First (19 файлов) сохранён отдельно, не применён в этом цикле.

## QA194-01
- Выбранный ID и ожидаемый URI передаются в маршрут; текущая публичная пара сохраняется атомарно. Не использовать `neighbor` для первоначального выбора или при исчезновении текущей записи из индекса. При отсутствии подтверждённого текущего файла вернуть понятное состояние/закрыть, не показывать соседний.
- Свежая запись приложения вне каталога проверяется адресно через актуальную запись истории, статус URI и физические алиасы; ограничение ожидания 5 с (кооперативная отмена провайдера), проверка privacy/access epoch/recovery. Существующий валидированный индекс остаётся основным для остальных элементов. Приватный и collection scope не расширяются через history fallback.
- Перестановка списка: pager сначала синхронизируется по ID, создание player и публикация settled page заблокированы до этого. Полная очередь и обычные жесты сохранены. При подтверждённом исчезновении выбранного элемента маршрут закрывается; не подставляет другой. Внутренний viewer при явном удалении может выбрать соседний элемент по прежней политике.
- Регрессии: missing requested ID, другой URI, direct app ref, privacy, reorder. Реальная запись экрана подтверждает симптом; причинная цепочка на устройстве требует ручной проверки.

## QA194-02
- Проверяется фактический MPEG audio stream (MediaExtractor), не только расширение; для неподходящего источника оригинал не меняется.
- Direct ID3: типовые v2.3/v2.4 без специальных флагов и без тега; две соседние MPEG Layer III frames; ограниченная длина тегов. Сохраняются неизменяемые ID3-кадры, аудиобайты и Xing/LAME, при наличии ID3v1 обновляются только соответствующие поля. Новая картинка нормализуется Android BitmapFactory в ограниченный JPEG, не нужен MJPEG encoder FFmpeg audio-tier. Существующая обложка сохраняется без новой, если это предусмотрено вызывающим кодом. Unsupported layout — контролируемый remux. Не заявляем сохранение произвольных неизвестных полей сложного тега при fallback.
- FFmpeg args array; нормализованная картинка копируется как attached_pic; резервный проход `-map 0:a:0 -vn -c:a copy` без старой/новой картинки. Результат проверяется через MediaMetadataRetriever. Ошибки: returnCode и классифицированная причина (без путей/тегов/URI/секретов), неизвестная причина остаётся unclassified. Сохраняются существующие проверки неизменного аудио, актуального SHA источника, доступа, резервной копии и отката в MediaRepository. Конкретный старый сбой FFmpeg по журналу не доказан.
- Синтетический реальный MP3: ID3 title/artist/album/cover, genre/comment сохранены, MPEG bytes и decoded SHA-256 совпали. JUnit + Android regression, затем полный CI. Конкретный пользовательский файл, Android grant, реальное устройство и аппаратная приёмка после выпуска.

### Дополнительное укрепление перед итоговым CI
- Обработчик карточки визуальной загрузки сначала берёт точную текущую запись Room, не запаздывающую проекцию. Для публичной app-записи актуальность ID/URI проверяется после асинхронной проверки файла; принадлежность к истории сохранена вместе с выбором. Исчезновение этой записи не разрешает подставить stale alias из индекса. Первый pager target всегда route item, сохранённый числовой индекс не определяет открываемый файл; добавлен тест отсутствующего initial selection.
- При любом успешном пути записи проверяются также ранее прочитанные неизменяемые распространённые поля (genre/year/track/disc/composer/album artist/writer, исходный album при отсутствии нового). Не удалось прочитать/сохранить подтверждённые поля — оригинал не заменяется. Опциональная ошибка нормализации обложки, в том числе превышение памяти, не блокирует теги. Неизвестные custom frames поддерживаемого прямого ID3 сохраняются; для сложного remux гарантировать произвольные нестандартные поля нельзя.
