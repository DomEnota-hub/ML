## Выявленные несоответствия в новом выборе папок

1. До этого этапа экран «Проверить всё» считал `rows.count(eligible)`, включая псевдодубли одной URI; дерево считало физический URI один раз. Единый `DuplicateFolderScope.availableFileCount` теперь совпадает с каталогом папок. Непроверенные и приватные строки в результат не попадают.
2. `relative_path` из MediaStore раньше обрезался `trim('/')`, из-за чего абсолютный или некорректный путь мог стать похожим на разрешённый относительный. Введена одна чистая проверка `verifiedDirectory`, применяемая при чтении и отображении: ровно один допустимый конечный `/` удаляется как стандарт MediaStore, ведущие и двойные разделители, обходы, обратные слеши, неизвестный volume и специальные символы отклоняются без создания дерева.
3. Compose тест длинного имени использовал неоднозначный поиск `onNodeWithText("1 файл", substring = true)`. Переведён на конкретную строку через testTag с проверкой текста.
4. Добавлены адресные проверки обзора с alias URI, неопределённого Gallery bucket, границ безопасного относительного пути и согласованности количества. Участвуют обе формы поиска.
