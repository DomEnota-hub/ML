Отдельное удаление существующего отчёта сохраняет прежний контракт; старые UI-записи не должны воскресить удалённый отчёт. Если пользователь отменил выбор, прежний поиск остаётся на паузе. При замене — явное подтверждение, проверка текущего поколения/доступа/непустой выбранной области/источника/token/epoch до удаления старого partial. Отдельное сохранение resumeSource и folder keys; продолжение разрешено только в исходной области и источнике. При запуске после подтверждённой замены старый partial удалён, завершённые отчёты сохранены; если каталог изменится уже после удаления, старт отклоняется и требует повторного выбора. Отпечатки по-прежнему проходят существующие проверки идентичности.
- QA-224-10: отдельная карточка и полноразмерный экран предварительных групп; доступ при работе/паузе только при актуальной разрешённой проекции. Pending и отсутствующий checkpoint не считаются нулём; 0 групп не открывается. Проверяются privacy epoch, ID/URI/каталог, минимум два действительных участника; сравнение без выбора и корзины. Back возвращает к основному экрану; окончательный отчёт и предварительный не смешиваются.

Поздняя запись прежнего задания отклоняется. Pause request сообщается как отдельное состояние, не маскирует commit.
