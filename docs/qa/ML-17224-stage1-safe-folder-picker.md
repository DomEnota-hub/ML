# MediaLoader 1.7.224 · этап 1 · безопасный выбор папок

Дата разработки: 23.11.2026 (МСК).
**База:** точный подписанный ARM64 QA 1.7.223, HEAD `23291b25177a02c7f136781afa677946e846dd73`. **Статус:** исходники и новые тесты внесены; на Xiaomi не проверено; QUALIFY/APK не запускались.

## Дефект

На Xiaomi Android 16 выборочная проверка дубликатов в Галерее и Музыке перекрывает нижнюю кнопку «Начать поиск» системными кнопками. Снимки 23.11.2026 20:43 показывают одинаковое перекрытие при 66 и 767 папках.

В 1.7.223 общий `DuplicateScanScopeDialog` использовал отдельное fullscreen Compose-окно `Dialog(decorFitsSystemWindows=false)`, внутренний `Scaffold(contentWindowInsets=WindowInsets(0,0,0,0))` и `navigationBarsPadding()` внутри нижней панели. Кнопка не прокручивалась, но безопасная область отдельного окна на реальном устройстве не подтверждалась. Robolectric тесты на SDK34 проверяли положение относительно viewport, но не относительно реальной системы Xiaomi Android16.

Историческая аналогия: 1.7.185 перевела основной экран музыкальных дубликатов в обычный `NavHost` (коммит `192e70d9d62a`) и добавила проверки footer в родительском `Scaffold` (`cba664d4b080`). Применить ту же архитектуру к выбору папок.

## Внесённые изменения

1. `DuplicateScanScopeScreen.kt` — общий полноэкранный composable **без Dialog/Popup и своего Android Window**, с прежними функциями дерева, поиска, сортировки, выборочных ключей, tri-state checkbox, счётчика и фиксированного footer.
2. Внутренний `Scaffold` получает уже ограниченные родительским `MediaLoaderApp` координаты. Убраны повторные `statusBarsPadding` и `navigationBarsPadding`, не нужно угадывать системную полосу в отдельном окне. `imePadding` остаётся для ввода текста.
3. `MusicDuplicatesDialog` и `VisualDuplicatesScreen` показывают общий выбор вместо своего содержимого в том же `NavHost`, когда `choosingScope=true`. Нет второго модального окна и не нужен ещё один back stack entry.
4. Удалён устаревший `DuplicateScanScopeDialog.kt`. Обработчики `onStart`, `onDismiss`, `beginScope`, `startScan` сохранены.
5. Для выбора папок работает двухступенчатый Back: из дерева → обзор области, из обзора → исходный экран дубликатов.
6. Тесты `DuplicateScanScopeDialogTest` адаптированы для новой архитектуры. Добавлены: `inAppPickerFooterRespectsActivitySafeDrawingBounds` и `pickerBackReturnsToScopeOverviewWithoutClosingRoute`. Обязательный JVM реестр 2461→2463, прежний разрешённый skip не изменён.
