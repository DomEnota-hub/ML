# ML — единый простой «Архив» вместо «Сейфа»

Статус: разработка начата по прямой команде владельца 21.11.2026. Основа — QA 1.7.210, `33e7d791062491187d8e8e87b5d298f8b726148b`. Документ не является подтверждением завершения интерфейса или аппаратной QA.

## Цель

В трёх разделах («Загрузчик», «Галерея», «Музыка»): `выделить → В архив → скрыто в обычных списках ML → Вернуть`. Один общий экран «Архив» с категориями. **Не сейф:** нет пароля, PIN, биометрии, идентификации, шифрования, второго закрытого хранилища. Новая архивная иконка вместо щита. Никаких изменений самих файлов при обычном логическом скрытии. Боковые программы/системная галерея Android не обязаны скрыть файл: это отдельное поведение, которое нельзя обещать без физического переноса.

## Первая техническая заготовка

`data/archive/SimpleArchivePolicy.kt` хранит строгую связь ID/URI/тип/размер для конкретного файла, не скрывает посторонние файлы в его физической папке. `SimpleArchiveStore.kt` атомарно сохраняет список, не меняет MediaStore и сами медиа. Старый `VaultScreen`, `PrivateScreen`, `ArchiveOverviewScreen` и их данные пока **не удалялись, не мигрировали, не открывались**; ввод нового движка не должен допустить утерю старых скрытых материалов.

## Следующие шаги после визуального согласования

1. Единая пользовательская иконка «Архив» без замка/щита; действие из каждого модуля; экран общих архивных файлов, фильтры по типу, выделение, возврат.
2. Подключение одного общего индекса к публичным коллекциям/поиску/плейлистам/миниатюрам и скачанным файлам, без удаления исходников. Проверка доступности при возврате; честный статус если файл удалён вне ML.
3. Отдельный доступ для переноса/восстановления старых зашифрованных файлов прежнего «Сейфа», не открывая их автоматически и не присоединяя скрытно к обычному незапертому Архиву. «Личное» никак не меняется.
4. Адресные регрессии, один полноценный CI на конечном SHA, ARM64 QA с оригинальной подписью DomEnota, Google Диск, затем устройство Xiaomi Android 16. Не повторять полные проверки без изменения исходного SHA.

## Границы этой заготовки

Не подключена к UI и не включает фактический перенос. В частности, отсутствие в обычных списках пока **не реализовано**, поэтому статус этого файла и branch — foundation only. Не переименовывать уже выпущенную 1.7.210 и не объявлять «Архив» готовым до сквозной аппаратной проверки.
