# MediaLoader 1.7.223 · итоги правок QA-222 и план аппаратной приёмки

Составлено 23.11.2026 МСК. Источник: подписанная QA 1.7.222 / 282, SHA `f8406c49753aec37694a24857cfc80b56267c8f8`. Изменения в рабочей ветке PR #187, без merge в main.

## Реализованные изменения относительно 1.7.222

**Поиск дубликатов · Галерея и Музыка**
1. Выборочный поиск: «Начать поиск» и сводка выбранных папок закреплены в отдельном нижнем слоте, с учётом system navigation и IME; дерево папок скроллится независимо. UI-проверка на Xiaomi с трёхкнопочной навигацией обязательна.
2. Перенос в «Личное»: проверка связи перенесённого файла с завершёнными отчётами, текущим и предварительным результатом, ID/URI/MediaStore/физическими алиасами. При **доказанной независимости** сохранять результаты и журнал; при активности сканирования, ошибке чтения, неизвестной идентичности и любом совпадении прежний строгий fail-closed сброс. Кэши распознавания/сравнения очищаются всегда.
3. Журнал: удаление конкретного **завершённого** отчёта с подтверждением, через атомарные указатели и durable tombstone, отдельно в шардированной Музыке и атомарной Галерее. Незавершённый поиск и файлы пользователя не удаляются; запрещено оживление удалённого отчёта поздним автосохранением. Глобальная очистка остаётся отдельной командой.
4. Предупреждения: единый компонент с обводкой, значком восклицания, заголовком и пояснением в принятых цветах активной темы. Для реально затронутого поиска корректный статус «Результаты требуют проверки». При переносе не относящегося к поиску файла предупреждение не показывается.

**Видеоредактор**
5. Круг кадрирования можно сдвигать за внутреннюю зону, продолжая менять его размер через границу; смещение ограничено исходным кадром.
6. Во время настройки круглого кадра весь источник виден без чёрного затемнения. Экспортный круг на чёрном фоне сохраняется.
7. Убрана постоянная поясняющая надпись для кадрирования.
8. Выбор клипа/переход по таймлайну сохраняет текущий инструмент; «Обрезка» включается только явно.
9. Устойчивость входа из видеоплеера: устранён мгновенный `popBackStack` после одного пустого кадра публичной проекции. Ожидание 2,2–35 секунд с учётом сканирования Галереи, запрет stale/private URI, проверка ID NavBackStackEntry перед отложенным выходом, диагностические события. Кодековый/GL crash в прежнем журнале не доказан.

**Фоторедактор**
10. Невидимые зоны углов увеличены, для обоих левых углов добавлен приоритет распознавания касания внутри края экрана. Центр маленькой рамки остаётся пригодным для перемещения; внешний размер точек не меняется.

**Закрыто без изменений:** происхождение `Instagram_66` (QA-222-06).

## Обязательные проверки перед подписанием

- Сохранность приватности: сравнение URI/ID/inode, случай переноса файла из группы, перенос постороннего файла, рестарт, восстановление приватного файла; никаких утечек через журнал, миниатюру или playback.
- Удаление одного старого / последнего музыкального и визуального отчёта, другой отчёт, активный scan, незавершённый checkpoint и позднее UI-сохранение.
- Галерея и Музыка на Xiaomi Android 16: выборочный поиск с 700+ папками, обе системы навигации, клавиатура, длинные пути, большой текст. CTA полностью видна и нажимается.
- Видеоредактор: круг сдвигается/масштабируется, фон во время настройки видим, экспорт имеет правильную маску, выбранный инструмент не сбрасывается, 10–15 входов из плеера и возвратов при обновлении MediaStore.
- Фоторедактор: по 20 касаний на каждом углу, рамка у краёв экрана, мелкая рамка и взаимодействие с pan/pinch.
- Обновление 1.7.222→1.7.223 поверх установленной версии без удаления пользовательских данных, сертификат DomEnota, версияCode 283, arm64-v8a, v2/v3.
