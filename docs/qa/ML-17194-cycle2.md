# ML 1.7.194 / 254 — цикл 2, этап 3: Cache First, коллекции

База: принятый HEAD цикла 1 `900d24df759f17f9862644a72f592221c6ef8933`. Исправления точной идентичности видео и MP3 сохранены. Черновик музыкальной статистики/истории не включён.

- Обычный маршрут коллекций и просмотр участника не запрашивают оба каталога и не ждут общий экран проверки. Адресное разрешение ID/URI; отдельная заявка на полный каталог для выбора новых файлов, обложки и явного повтора старой неоднозначной идентичности. Выбор аудио использует отдельный аудиокаталог.
- Постоянные атомарные ограниченные снимки состава и первых обложек; ключи схемы, приватности, разрешений. App-строки повторно сверяются с Room (ID, URI, тип, размер, время, публичность). Внешний снимок допускается только при полном доступе, совпадении версии/поколения MediaStore и identity; старые API без поколений и частичный доступ требуют свежей проверки. Снимок не доказывает доступность для действий. Отзыв разрешений, private/hidden, удаление, смена идентичности имеют приоритет.
- Одно адресное задание на поколение/guard с conflated запросами, публикация только актуального результата. Ограничение двух provider workers; 1.5 с на адрес, 12 с на проход (плюс ограниченное чтение/сверка stamp). Некорректный провайдер не блокирует UI даже если игнорирует отмену. Pending не равен MISSING. Последний разрешённый снимок сохраняется при обычном обновлении; без него появляется честное состояние повтора. Добавление файлов также имеет ограниченный визуальный срок ожидания.
- Обзор коллекций: отдельный бюджет, первые 3 кандидата и ранее сохранённая обложка; при отсутствии подтверждения нейтральный placeholder, не скачивать оригиналы удалённо. Обложка и состав не ждут общего индекса. Статус/guard и текущая membership проверяются. Кеш миниатюр ограничен существующей политикой.
- Адресные уведомления MediaStore сгруппированы; завершённый неизменный каталог не публикует новую ревизию. Существующий generation/version cache общего каталога сохранён; при реальной смене поколения его полный fallback остаётся, новый универсальный delta-сканер не введён. Нагрузочные замеры на Xiaomi и корректность конкретной коллекции из журнала обязательны после общего выпуска.
- Новые тесты: кеш после перезапуска/повреждение/доступ/identity, pending/confirmed missing, bounded provider, independent catalog requests, большая библиотека и 18 членов, equality/revision, serial projection, UI без бесконечного индикатора. Итоговые CI должны подтвердить компиляцию, полный JVM, оба lint и ARM64. Промежуточная подпись/выдача отсутствуют.

Follow-up перед приёмкой: отдельный подтверждённый empty state после Room/privacy; явный immutable `CollectionCoverAccess` обновляет сохранённую пользовательскую обложку при отзыве photo-разрешения даже при неизменной membership. Источник публичной app-обложки может быть вне коллекции; требуется текущая публичная строка. Identity-bound аудиообложки имеют URI-specific invalidation, включая запрет публикации устаревшего декодирования после замены тегов. Добавлены три адресные регрессии.

Последнее укрепление: обзор получает только history-строки и сигналы MediaStore, относящиеся к участникам коллекций. Независимый 16-секундный предел начального видимого ожидания детали не сбрасывается при смене поколений провайдера; по истечении отображается действие повтора. Ранее подтверждённые данные не скрываются при обычном обновлении. Добавлен UI-тест непрерывного ожидания и проверка нерелевантного изменения history.
