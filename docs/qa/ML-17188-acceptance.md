## Обязательные аппаратные сценарии

Ни один пункт ниже ещё не отмечен как пройденный: устройства нет в `adb devices -l`, `/dev/kvm` отсутствует.

- [ ] Установка поверх247: история, избранное, коллекции/альбомы, личные файлы, плейлисты и настройки сохранены.
- [ ] Светлая, тёмная и INFERNUM; крупный шрифт; portrait/landscape; жестовая и3кнопочная навигация; IME не перекрывает действия.
- [ ] 30с музыки на неизменном экране: диагностические счётчики не показывают повторных scan/query/decode из-за position ticks; возврат не множит подписки.
- [ ] При смене приватности прошлые публичные данные исчезают сразу; фоновая операция не публикует их снова.
- [ ] Реальная потерянная запись восстанавливается именно на прежнем месте, с прежними связями; обычная новая загрузка остаётся новой.
- [ ] Видео с несколькими дорожками в Галерее и Личном: переключение без сброса позиции и прежних данных другого видео.
- [ ] Пакетный экспорт совпадает с preview по фильтру/силе, не содержит служебных рамок, не изменяет оригиналы; очередь сохраняет retry/cancel.
- [ ] Акустические и возможные совпадения не включаются автоматически в массовую корзину; подтверждённый выбор сохраняет минимум один экземпляр.

## Существенные ограничения

Системный Android DATE_ADDED восстановленного файла может быть новым; ML использует первоначальную дату истории и сохраняет свою хронологию. При завершении процесса строго между публикацией файла download engine и возвратом результата возможен физический файл без обновлённой ссылки; исходная запись не теряется, подбор по имени вместо проверенной идентичности не применяется. QA16 не включает переработку общего downloader. Восстановление приватной записи через этот публичный путь заблокировано. QA02 и QA10 дополнительно разрешены пользователем14.11.2026 в18:04МСК и включены в текущую реализацию; аппаратная приёмка остаётся открытой. Полноценная проверка на Xiaomi не заменяется JVM/Compose тестами.
