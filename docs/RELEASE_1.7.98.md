# MediaLoader 1.7.98 (160)

- Мини-плеер учитывает системную панель и на экранах альбомов/плейлистов.
- В мини-плеере: обложка, название, исполнитель, предыдущий трек, воспроизведение/
  пауза, следующий трек и закрытие. Полоса прогресса без лишней точки.
- Проверенные списки сохраняются в памяти. При неизменном полном доступе обновление
  идёт в фоне, повторный вход не вызывает полноэкранную проверку. Изменения MediaStore
  отслеживаются наблюдателем; изменение разрешений и ограниченный доступ требуют
  повторной проверки для защиты скрытых/недоступных файлов.
- Для плейлистов используется музыкальная иконка списка.
- Возврат из настроек открывает существующий экран Галереи/Музыки, сохраняя выбор.
- Очередь: перестановка за маркер, действия выше/ниже, убрать из очереди.
- Меню трека: играть следующим, добавить в конец очереди. Текущая позиция сохраняется;
  файлы и сохранённые плейлисты не меняются.
