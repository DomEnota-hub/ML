# MediaLoader 1.7.96

## Автоматическая загрузка Instagram

Прямые ссылки «Поделиться», адресованные главному окну приложения, теперь проходят
ту же проверку режима, что и обычное окно приёма ссылок. Исправлены холодный запуск
и повторная отправка в уже существующее окно. Автоматическая ссылка не открывает
окно выбора и передаётся существующему фоновому загрузчику с его защитой от дублей.
При возврате к источнику приложение ждёт сохранения фоновой задачи. В диагностике
появились безопасные отметки точки входа и выбранного режима без полных ссылок/cookie.

## Галерея и Музыка

- Новый компактный интерфейс обеих тем по согласованному варианту А.
- Общий селектор источника: «Все файлы телефона» включает и файлы приложения;
  один физический файл показывается один раз.
- Галерея: плотная сетка, даты, альбомы с обложками, отдельный заголовок альбома.
  Фото и видео перелистываются свайпом без боковых стрелок; видео запускается
  только по нажатию воспроизведения.
- Музыка: обложки и плейлисты, отдельный экран добавления с прослушиванием и
  кнопками выбора, сохранение выбора при смене источника и повороте.
- Полный музыкальный плеер и мини-плеер используют одну фоновую очередь.
- Общий пятиполосный эквалайзер с пресетами и сохранением настроек. Реальная
  программная обработка звука; неподдерживаемая текущей частотой полоса обозначена.
- Плавающее видео: нижняя полоса с перемоткой нажатием и перетаскиванием.
  Основная полоса видео приближена к нижним кнопкам управления.
- Плейлисты сохраняют альтернативные ссылки после очистки истории без удаления
  файлов; прогресс видео общий для разных адресов одного файла.
- Проверка разрешений скрывает прежние миниатюры до обновления индекса, сохраняя
  несохранённые правки редактора и выбранные треки.
