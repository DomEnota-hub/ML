# MediaLoader 1.7.21 (83): VK реклама и просмотр

## Изменения

- Сканер читает явную отметку рекламы VK. Изображения такой публикации попадают в результаты снятыми с выбора; «Выбрать все» не включает их повторно. Пользователь может выбрать их вручную.
- Признаки рекламы в тексте публикации дают метку «Возможная реклама», но сохраняют выбор. Текст, встроенный только в изображение, не распознаётся.
- Статус рекламы хранится в базе результатов. Переход схемы с версии 1 на версию 2 добавляет колонку со значением `NONE` для прежних записей и сохраняет их выбор.
- Добавлена сетка из четырёх изображений в ряд и переключение на список; выбор вида сохраняется. Технический ID публикации убран из результата.
- Увеличенный просмотр поддерживает свайпы через весь список результатов и изменение выбранности в левом верхнем углу. Команда «Снять публикацию» исключает все ещё не скачанные изображения одного поста.
- Статус ключа VK отображается зелёным после проверки и красным с пояснением в остальных случаях.
- У избранного сообщества вместо текстовой кнопки удаления стоит крестик; удаление требует подтверждения.

## Проверка

- `:app:testDebugUnitTest`: 385 тестов, 0 ошибок.
- `:app:lintDebug`: 0 ошибок.
- `:app:assembleRelease -Parm64Release`: успешно.
- Переход старой схемы и правило «Выбрать все» для рекламы отдельно проверены на SQLite с сохранённой записью.
- Сборка предназначена для `com.domenota.medialoader`, версии 1.7.21 (83), ARM64 и прежнего сертификата DomEnota.

Подключённого устройства нет, поэтому свайпы и внешний вид нужно проверить после установки на телефоне. VK может не помечать встроенную рекламу официальным флагом; в таком случае её можно снять вручную по всей публикации.
