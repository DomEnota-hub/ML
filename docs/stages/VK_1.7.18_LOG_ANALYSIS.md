# Журнал 1.7.18 и тестовое обновление 1.7.19

Журнал 1.7.18 с телефона показывает `api_code=1051 method=utils.resolveScreenName` при сканировании сообщества. Пользователь указал адрес `schrodinger_humor`; точный введённый домен журнал не сохраняет. Запрос `wall.get` не выполнялся. По числовому коду без описания ответа нельзя утверждать, что сервисный ключ недействителен или что сообщество закрыто.

В 1.7.19 предварительное разрешение короткого имени через `utils.resolveScreenName` удалено. `wall.get` вызывается непосредственно с параметром `domain`. До обработки постов ответ проверяется: владельцы публикаций должны иметь отрицательный `owner_id` (сообщество); личные стены отклоняются. Если у адреса нет публикаций и его тип нельзя подтвердить, показывается отдельное сообщение.

Проверены тестами положительный ответ стены сообщества, отклонение личной стены и случай пустой стены. Реальный `wall.get` с сервисным ключом пользователя требует проверки на телефоне. При повторной ошибке расширенный журнал покажет метод и код ответа VK.
