# Проверка совместимости с установленной 1.7.16 (78)

Эталон: `MediaLoader_1.7.16_78_ARM64_DomEnota_TEST_SIGNED.apk`, SHA-256 `902a43673a9f9ce518c630d8f39eab1b3cd3422ceb33b68a90ba2b16b79b990d`.

Проверено ограниченным чтением APK, без восстановления исходников:

- `aapt dump badging`: package `com.domenota.medialoader`, versionCode `78`, versionName `1.7.16`, minSdk 26, targetSdk 35.
- `apksigner verify --print-certs`: сертификат SHA-256 `4f6f0ddf4d8fd2669fd2a3a6ebab6e84bda17281a3a5badada0e1eeb73a4f1d2` (DomEnota).
- Нативные библиотеки APK расположены только в `lib/arm64-v8a/`.
- Основная Room `media-loader.db`: `HistoryDatabase_Impl` создаёт delegate версии **10** с identity hash `b262dc69fbd8610a7283ec19b822b692`. Полные SQL `CREATE TABLE downloads` и `CREATE TABLE settings` побайтно совпадают с генерируемыми исходниками 1.7.15, на которых основана 1.7.17.
- `bulk-jobs.db` и её таблица `bulk_state` присутствуют в APK; исходники 1.7.15 используют те же имя файла и SQL таблицы. Новая работа их не изменяет.
- Экспериментальная 1.7.16 также содержит отдельную `vk-wall-archive.db`, версия SQLiteOpenHelper 1, таблица `posts (key, date_sec, snippet, payload, file_count, selected)`. Новая функция использует другой файл `vk-community-images.db`; старый архив открывается только для просмотра и не удаляется. В новом экране есть просмотр заголовков старых публикаций без использования их прежних ссылок на файлы.
- В APK `android:allowBackup=false`. Обновление с тем же package ID и сертификатом оставляет локальные файлы приложения на месте; однако этот вывод требует проверки на тестовом устройстве с реальными данными.

## Ещё не проверено

- Установка кандидата 1.7.17 поверх **установленной** 1.7.16 с сохранёнными историей, архивом VK, настройками и SAF-разрешениями: в среде нет подключённого Android-устройства или эмулятора.
- Реальное содержимое пользовательской `vk-wall-archive.db` неизвестно; просмотр через новый экран необходимо проверить на телефоне.
- Доступность `wall.get` с конкретным сервисным ключом пользователя не проверена: ключ не передавался в рабочую среду.

Не объявлять релиз завершённым до проверки обновления на устройстве и реального ответа VK API.
