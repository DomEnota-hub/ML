# MediaLoader 1.7.17 — этапы 3–9

## Реализовано

- Отдельный экран поиска изображений сообществ VK, календарём диапазона дат, списком результатов и выбором материалов до загрузки.
- Сервисный ключ VK хранится в Android Keystore; запросы `wall.get` выполняются через VK API. Личные страницы отклоняются.
- Постраничное сканирование и фоновая загрузка с контрольными точками, отменой, ограниченными повторами и отображением прогресса.
- Проверка типа изображения по содержимому, отбор статичных JPEG/PNG/WebP, устранение повторов по VK ID и SHA-256. Сохранённые файлы попадают в обычную историю загрузок, сгруппированную по публикации.
- Экспериментальная база `vk-wall-archive.db` версии 1.7.16 доступна только для просмотра. Новые данные хранятся отдельно.
- Версия приложения: 1.7.17 (79).
