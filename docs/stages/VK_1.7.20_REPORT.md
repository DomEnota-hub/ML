# MediaLoader 1.7.20 (82): VK результаты, избранное и журнал

## Сделано

- Поиск открывает отдельный экран результатов. На нём доступны страницы по 60 изображений, выбор всех или снятие выбора, круглые независимые отметки и загрузка выбранного.
- Нажатие на миниатюру открывает полноэкранный просмотр с вписанным изображением. Недоступная ссылка показывает сообщение.
- Адреса сообществ можно сохранять в локальное избранное с названием, выбирать повторно и удалять. Домены `vk.ru` и `vk.com` одного короткого адреса объединяются.
- Журнал показывает последние 500 заданий с датами, итогами и сохранёнными результатами. Повторение запускает новый поиск с прежним сообществом, периодом и часовым поясом. Удаление записи и очистка журнала сохраняют скачанные файлы, индекс дубликатов, обычную историю загрузок и сервисный ключ. Активные задания не удаляются.
- Кнопка просмотра архива 1.7.16 убрана. Сам файл старой базы не изменён.
