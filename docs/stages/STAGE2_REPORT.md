# MediaLoader 1.7.17 — этап 2 / 9

Статус: завершён на уровне исходников и доступных автоматических проверок.

## Что изменено

- HitMoz: все состояния действия в строке трека занимают 48 × 48 dp; индикатор 24 dp расположен по центру.
- Подтверждённое распознавание: после замены MP3 сбрасывается локальная миниатюра, карточки перечитывают её даже при прежнем URI. Подтверждённая обложка Shazam имеет приоритет перед миниатюрой публикации, когда встроенная недоступна.
- Удалённые обложки: одновременные запросы одного URL объединены; 403 временно блокируется, для 429/5xx/сетевых ошибок применяется ограниченная задержка повторов. Если локальная обложка читается, запрос к CDN не начинается.
