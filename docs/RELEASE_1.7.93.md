# MediaLoader 1.7.93

## Личное

- Завершённые публичные файлы и группы переносятся в настроенное «Личное» без PIN/отпечатка и без открытия приватного содержимого. Пользователь остаётся в текущем разделе.
- При первом переносе сначала выбирается способ защиты, затем выполняется перенос и возврат в исходный раздел. Запрос настройки сохраняется при пересоздании экрана; пакетное выполнение принадлежит ViewModel.
- Вход по биометрии запрашивается автоматически при открытии раздела. После отмены доступна кнопка «Повторить вход», без повторного автоматического запроса.
- Ручная блокировка не запускает вход сама, в том числе после восстановления экрана.
- Просмотр, возврат, удаление и смена защиты по-прежнему требуют входа. Повторный вызов переноса уже приватного файла не обходит защиту.

## Группы

- На рамке группы появилась кнопка ⋮, доступная и при свёрнутой группе.
- «В избранное» добавляет всех участников; если все уже избранные — убирает всех. Смешанное состояние не инвертирует каждый файл отдельно.
- «Добавить в папку» назначает одну папку всем участникам.
- «Переместить в личное» переносит всю группу без запроса доступа.
- «Удалить» выделено красным, спрашивает подтверждение с количеством и переносит завершённые файлы в корзину.
- Учитываются все файлы текущей группы, включая записи за «Показать ещё». Незавершённые и неудачные задачи не считаются успешно обработанными файлами. Частичный результат показывает число успехов и ошибок.
- Папки и «Личное» сохраняют исходную группировку. В списке — группы с раскрытием, в сетке — отдельные миниатюры по четыре в ряд. Раздел содержит только находящуюся в нём часть исходной группы.
- В «Личном» доступны групповые избранное/папка, возврат и постоянное удаление с предупреждением. Вид списка/сетки запоминается отдельно.

## Надёжность

Сохранены проверка приватной копии, порядок записи базы и удаления публичного источника, а также повтор завершения неудачного переноса. Отмена пакетной операции проверяется и после финального неотменяемого сохранения: ложное сообщение об успехе не показывается.
При остановке процесса во время переноса уже сохранённые файлы остаются защищены; незавершённые публичные копии отмечены для повторной очистки. Гарантия непрерывного фонового выполнения после завершения процесса не добавлялась.

## Проверка

Регрессии: перенос при заблокированном разделе, запрет чтения/возврата/удаления, автоматический реальный системный запрос и отмена, восстановление ручной блокировки, группы из 30 файлов, смешанное избранное, частичные ошибки, отмена в финальном commit, неполная активная группа, приватная сетка и скрытие данных до входа.
Системные запросы проверены через Robolectric (биометрия — платформенный shadow, резервный вход — Android intent). Физический телефон недоступен.
